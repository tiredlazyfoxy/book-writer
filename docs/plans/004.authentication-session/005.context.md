## Gate placement note
The token gate runs at SPA mount (before rendering routed content). Reading
`getToken()` at module/mount time and redirecting is a plain imperative check —
it is not a `<Page>State` load and does not need the async trio. Keep it minimal
and outside React Router's route tree so it fires before any page mounts.
