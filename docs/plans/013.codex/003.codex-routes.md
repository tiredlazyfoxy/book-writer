# 003 — Codex routes

## Goal

Expose the codex service over the existing book-scoped `/api/books/{book_id}/…` route family, with
the reason→status map, the authz error mapping and the router wiring in `main.py`.

## Source files

```
backend/app/routes/codex.py
backend/app/main.py
```

## Test files

```
backend/tests/routes/test_codex.py
```

## Interface intent

**`backend/app/routes/codex.py`** — a new router with prefix `/api/books` and tag `codex`, mounted
bare in `main.py` beside the existing routers.

Four endpoints, all resolving membership through `Depends(authz.book_access)` and **not** declaring
`book_id` themselves:

- **`POST /{book_id}/codex`** — create an entry from the create-request body. Returns the entry
  response with `201 Created`. (UC-069)
- **`GET /{book_id}/codex`** — list the book's entries. Query parameters: the entry `kind` (optional
  — absent means all kinds), a free-text needle `q` (optional), and an include-archived flag
  (optional, default false). Returns the list envelope. (UC-071)
- **`GET /{book_id}/codex/{entry_id}`** — one entry. (UC-070 step 1)
- **`PUT /{book_id}/codex/{entry_id}`** — full-replace update from the update-request body, carrying
  the expected `modified_at`. Returns the updated entry response. (UC-070)

Supporting shapes:

- **a module-level reason→status dict** mapping the codex service's reason enum to HTTP status:
  not-found → **404**; name-required / name-not-allowed / archived → **400**; stale `modified_at` →
  **409**; proposal-mode-unsupported → **403** (see `context.md` → "Planner-derived decisions" for
  why 403 and not 404 or 501).
- **a `_map_codex_error` helper** turning the service error into an `HTTPException` through that dict,
  with the reason value in the detail body so the client can branch on it.
- **the standard `authz.BookAuthorizationError` → 403 mapping**, copied from the existing routers.

**`backend/app/main.py`** — include the new router. No other change.

Route ordering: the static `codex` segment sits under the `{book_id}` param that the dependency
consumes, and `/{book_id}/codex` is declared **before** `/{book_id}/codex/{entry_id}`.

## Definition of done

1. `[test]` `POST` with a valid character payload returns **201** and a body that validates as the
   entry response DTO, with string ids. (UC-069 / US-078.AC-1)
2. `[test]` `POST` with a fact payload carrying a name returns **400** with the name-not-allowed
   reason in the detail. (US-078.AC-2)
3. `[test]` `POST` for a character with no name returns **400** with the name-required reason.
   (US-078.AC-1)
4. `[test]` `GET` list returns only entries of the requested `kind`, and returns every kind when the
   parameter is omitted. (UC-071 / US-080.AC-1)
5. `[test]` `GET` list with `q` returns only entries whose name or body contains the needle,
   case-insensitively. (US-080.AC-1)
6. `[test]` `GET` list excludes archived entries by default and includes them when the flag is set.
   (UC-071)
7. `[test]` `GET` one returns the entry; an unknown entry id, and an entry id belonging to another
   book, both return **404**. (US-085.AC-1)
8. `[test]` `PUT` with the current `modified_at` applies the edit and returns the updated DTO with a
   later `modified_at`. (UC-070 / US-079.AC-1)
9. `[test]` `PUT` with a stale `modified_at` returns **409** and leaves the entry unchanged.
   (`frontend-workspace.md` → stale buffer)
10. `[test]` `PUT` on an archived entry returns **400**. (UC-070 precondition)
11. `[test]` A co-author's `POST` and `PUT` on a **proposal**-mode book return **403** with the
    proposal-unsupported reason; the owner's succeed. (decision 3; US-079.AC-2 knowingly unmet)
12. `[test]` A non-member of a private book gets **404** from **every** one of the four routes —
    the canonical shape copied from `test_chats.py:test_non_member_gets_404_from_every_route__DoD9`.
    (US-085.AC-1)
13. `[test]` A logged-in reader of a **public** book gets **403** from every one of the four routes:
    the book is visible, the codex is not. (US-085.AC-1)
14. `[test]` A request with no bearer token gets **401** from every route. (`authorization.md` →
    Failure modes)
