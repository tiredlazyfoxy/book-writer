# Step 002 — Async DB engine & session-free db/ core

## Goal
Build the async SQLite engine and the session-free `db/` primitives — `DbConfig`, engine init + schema creation, the single session primitive, a readiness ping, a LanceDB init stub, and the temp-DB test fixture.

## Source files
backend/app/db/engine.py
backend/app/db/health.py
backend/app/db/vector.py

## Test files
backend/tests/conftest.py
backend/tests/db/test_engine.py

## Interface intent
- **`DbConfig`** (in `db/engine.py`) — a `@dataclass` holding `db_path` (a `Path`, injectable for tests) and `echo` (bool, default False). Exact shape given in `backend.md`; see `002.context.md`.
- **`init_engine(config)`** — initializes the module-level engine singleton from a `DbConfig`: ensures the parent directory of `db_path` exists, builds the `sqlite+aiosqlite:///{db_path}` async engine, stores it (and the config) in module-level singletons. Idempotent-safe to call once per process/test.
- **`init_db()`** — invokes the model-registration hook, then creates schema via `SQLModel.metadata.create_all` inside `async with _engine.begin() as conn: await conn.run_sync(...)`. Includes an **idempotent, additive in-code `ALTER TABLE ... ADD COLUMN` migration seam** (try/except, no-op for now — no columns to add). No Alembic.
- **model-registration hook** — a function that imports every `app.models.*` table module (`# noqa: F401`) so tables register on `SQLModel.metadata` before `create_all`. **Empty for now** — there are no models yet; leave the structure with a comment marking where future model imports go.
- **`get_standalone_session()`** — returns a fresh `AsyncSession` bound to the engine singleton; **raises** a clear error if the engine is uninitialized. This is the **only** session primitive `db/` modules use. Sessions never leak past `db/`.
- **`ping()`** (in `db/health.py`) — session-free readiness check: opens its own session via `get_standalone_session()`, runs a trivial `SELECT 1`-style probe, returns a plain readiness signal (e.g. a bool or `"ready"`). No session or ORM type leaks out.
- **`init_vector(...)` / vector stub** (in `db/vector.py`) — a thin LanceDB connect/init stub that opens a connection to the configured LanceDB directory. Unused until a vector-backed model exists; must import and initialize without error (Decision 2).
- **`conftest.py` (create)** — a session/temp-dir-scoped fixture that builds a throwaway `DbConfig` pointing at a temp SQLite file and calls `init_engine` + `init_db`, giving each test run an isolated DB. Do **not** override `event_loop` (rely on `asyncio_mode="auto"`).

## Definition of done
1. `[test]` After `init_engine` + `init_db` against an injected temp `DbConfig`, the schema builds without error and calling `init_db()` a second time is a safe no-op (idempotent, additive).
2. `[test]` `db.health.ping()` returns a ready result after the engine is initialized.
3. `[test]` `get_standalone_session()` raises when called before `init_engine` (engine uninitialized).
4. `[test]` `init_engine` honors the injected `DbConfig.db_path` — the throwaway SQLite file is created at the injected path, not the default.
5. `[manual/live]` `db/vector.py` imports and its init stub opens a LanceDB connection against a configured directory without error.
