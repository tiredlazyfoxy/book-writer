## Settings class (net-new — the reference has none)
`app/settings.py` holds a `pydantic-settings` `BaseSettings` subclass plus a cached `get_settings()`. Requirements:
- Loads `.env.local` (pydantic-settings `env_file`).
- Resolves the SQLite DB path honoring the `BOOKWRITER_DB_PATH` env var; dev default `backend/data/bookwriter.db`.
- Exposes a LanceDB directory path field (consumed later by `db/vector.py` in step 002); a sensible default under the data dir.
- `get_settings()` returns a single shared instance (cache it).
- Keep `Settings` separate from `DbConfig` — see the "Settings vs DbConfig" section of `context.md`.
