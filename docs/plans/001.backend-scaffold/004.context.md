# 004.context — JSONL import/export mechanism hook

## Mechanism split (mirror the reference)
Reference: `D:/GitRoot/_TextGens/LLMRPTextOnlyProject/backend/app/db/import_export_queries.py` + `.../app/services/db_import_export.py`. The layer split is strict:
- **db/ layer** (`import_export_queries.py`) — generic, session-free primitives only, **no serialization**:
  - `export_table(model_class, callback)`: iterate rows, call `callback(row)` per row (per-row streaming, no bulk load).
  - `upsert_batch(items)`: `session.merge` per item + one commit — the streaming UPSERT primitive.
  - `run_vector_rebuild()`: stub to rebuild the LanceDB sidecar from SQLite rows (no-op now).
- **services/ layer** (`db_import_export.py`) — holds the registry and does serialization:
  - `TABLE_REGISTRY`: ordered `(zip_filename, model_class, to_dict_fn, from_dict_fn)` tuples in FK dependency order. **Empty for 001.**
  - `BATCH_SIZE = 100`.
  - `export_all() -> bytes`: zip of `<table>.jsonl.gz`, each streamed per-row into gzip using `export_table` + a serializing callback.
  - `import_all(zip_bytes)`: call `init_db()` first, then stream lines, accumulate `BATCH_SIZE`, flush via `upsert_batch`; run `run_vector_rebuild()` after. UPSERT / idempotent.
