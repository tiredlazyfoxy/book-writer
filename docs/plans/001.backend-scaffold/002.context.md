# 002.context — Async DB engine & session-free db/ core

## DbConfig shape (from backend.md)
```
@dataclass
class DbConfig:
    db_path: Path       # SQLite file path (injectable for tests)
    echo: bool = False  # SQLAlchemy echo for debugging
```
Keep it exactly this shape. It is the db-layer injectable — distinct from `Settings` (step 001). See "Settings vs DbConfig" in `context.md`.

## Engine module pattern (mirror the reference)
Reference: `D:/GitRoot/_TextGens/LLMRPTextOnlyProject/backend/app/db/engine.py`. Follow its structure:
- Module-level `_config` / `_engine` singletons.
- URL `sqlite+aiosqlite:///{db_path}`.
- `init_engine(config)`: mkdir parent, `create_async_engine`, store singletons.
- `init_db()`: run the registration hook, then `async with _engine.begin() as conn: await conn.run_sync(SQLModel.metadata.create_all)`, then the idempotent `ALTER TABLE ... ADD COLUMN` try/except migration seam (no-op now).
- `get_standalone_session() -> AsyncSession`: raise if engine uninitialized; the **only** session primitive db/ modules use.
- Model-registration hook: imports every `app.models.*` module (`# noqa: F401`) so tables register before `create_all`. **Empty now** — no models exist; leave a marked seam for future imports.

## Session-free db/ module shape
`db/health.py`'s `ping()` opens/closes its own session via `get_standalone_session()` and returns a plain type (bool or `"ready"`) — no `AsyncSession`, `select()`, or ORM row leaks past `db/`. This is the reference's session-free module contract.
