## Interface intent
- **`pyproject.toml`** — packages the backend as `bookwriter-backend` with setuptools. Carries the **verbatim** dependency block from `backend.md` (see `001.context.md` for the exact anchor and the rule to keep the `llm-client @ git+...@v0.1.4` line unchanged), the `dev` optional-dependencies (pytest, pytest-asyncio, httpx), `[tool.setuptools.packages.find]` with `include=["app*"]`, and `[tool.pytest.ini_options]` with `asyncio_mode="auto"`.
- **`Settings`** (in `app/settings.py`) — a `pydantic-settings` `BaseSettings` app-config class. Loads `.env.local`. Exposes the resolved SQLite DB path, honoring the `BOOKWRITER_DB_PATH` environment override and falling back to the dev default (`backend/data/bookwriter.db`). Also exposes the LanceDB directory path (used later by `db/vector.py`). Keep it distinct from `DbConfig` (see `context.md`).
- **`get_settings()`** — module-level accessor returning a cached/singleton `Settings` instance so the app and tests share one config object.
- **Package `__init__.py` files** — mark `app`, `app/routes`, `app/services`, `app/db`, `app/models`, `app/models/schemas` as importable packages. Empty (or a short docstring); no logic.
- **`.gitignore`** — ignores `.venv/`, `data/`, `.env.local`, `*.db`.

## Definition of done
1. `[test]` `Settings` (via `get_settings()`) resolves the DB path from the `BOOKWRITER_DB_PATH` environment variable when it is set.
2. `[test]` `Settings` falls back to the documented dev-default DB path when `BOOKWRITER_DB_PATH` is unset.
3. `[test]` `get_settings()` returns the same instance on repeated calls (single shared config object).
4. `[manual/live]` `.venv/Scripts/pip install -e .[dev]` from `backend/` succeeds and resolves the full dependency block (including the `llm-client` git dependency).
5. `[manual/live]` `import app`, `import app.routes`, `import app.services`, `import app.db`, `import app.models`, `import app.models.schemas` all import cleanly (package tree is valid).
