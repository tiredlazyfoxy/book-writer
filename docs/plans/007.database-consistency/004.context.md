# Step 004 — step-specific context

D6 (the load-bearing scope decision) is in `context.md` — read it; it governs exactly what
this step does and does NOT build.

Narrow to this step:

- **The no-provider contract is a decision the skeleton must freeze and the test binds to.**
  Two admissible shapes: (a) raise `DbAdminError(no-provider)` when
  `get_embedding_server()` is `None` or `embedding_model` is unset; or (b) still perform the
  index reset and return a status flag indicating no provider. Either satisfies "the reset
  stays valid regardless." Pick one in the skeleton; the test in DoD-3 asserts the chosen
  one. Prefer the option that gives the admin meaningful feedback (a) unless the reset must
  always run for post-import correctness — decide with the reset semantics in mind.
- **`get_embedding_server()` returns the `is_embedding` row but does NOT guarantee
  `embedding_model` is non-null** (006 contract). This step validates `embedding_model`
  itself — that is why the 006 dependency is "real."
- **LanceDB directory** comes from the `Settings` field the 001 skeleton froze (reference
  `app/settings.py`; do not hardcode a path or field name). Tests point it at a throwaway
  temp dir the same way the temp-DB fixture works.
- **`run_vector_rebuild` signature is already frozen** by the 001 skeleton (it was the
  no-op stub). Implement its body only; do not change its signature — if the delegation
  needs a different shape, re-route to skeleton.
- **Empty registry means count 0** — with `VECTOR_SOURCE_REGISTRY == []` there are no rows
  to embed, so the reset completes at zero. Do not add users/llm_servers as vector sources;
  they are not searchable content (Stage-2 codex is the first source, behind the architect
  gate).
- Tests monkeypatch `get_embedding_server` for the designated / none cases and
  `db.vector.rebuild_index` for the delegation assertion.
