# Step 005 — Admin DB routes + main wiring (HTTP surface)

## Goal
Expose the db-admin service over HTTP: six admin-gated endpoints under `/api/admin/db`
(report, create, sync, export-download, import-upload, vector-rebuild), each mapping
`DbAdminError.case` to a status, and wire the router into the app.

## Source files
backend/app/routes/admin/db.py
backend/app/routes/admin/__init__.py
backend/app/main.py

## Test files
backend/tests/routes/admin/test_db.py

## Interface intent
- **`app/routes/admin/db.py`** — an `APIRouter` with prefix `/api/admin/db`, every
  endpoint `Depends(require_role(admin))` (006/005 admin-gating substrate). Each handler is
  HTTP-only: parse → one `services.db_admin` call → map `DbAdminError.case` → status →
  return. Endpoints (declare static paths before the `/{name}` param paths):
  - **`GET /report`** — `build_consistency_report()` → the report DTO, 200.
  - **`GET /export`** — `export_database()` → a downloadable response (`Response` /
    `StreamingResponse`) carrying the zip bytes, a zip media type, and
    `Content-Disposition: attachment; filename=...zip`, 200.
  - **`POST /import`** — accepts a **multipart `UploadFile` field named `file`** (mirror
    003's receive shape), reads bytes, calls `import_database(bytes)`; 200/204 on success,
    400 on `invalid-archive`.
  - **`POST /vector/rebuild`** — `rebuild_vector_index()` → 200 (returning the count /
    status), or the no-provider mapping per step 004's frozen contract.
  - **`POST /tables/{name}/create`** — `create_missing_table(name)` → 200/204; maps
    `not-in-metadata`/`table-not-missing` → 400.
  - **`POST /tables/{name}/sync`** — `sync_table_schema(name)` → 200/204; maps
    `unknown-table` → 404.
  - The **`DbAdminError.case` → status map**: `invalid-archive` / `table-not-missing` /
    `not-in-metadata` → 400; `unknown-table` → 404; no-provider per step 004's contract;
    success → 200/204. Non-admin → 403 from the guard.
- **`app/routes/admin/__init__.py`** — amend only if the admin package aggregates routers
  for mounting; otherwise leave as-is.
- **`app/main.py`** — one `app.include_router(...)` for the db-admin router (composition
  root), alongside the existing auth + admin-users + admin-llm-servers routers.

## Definition of done
1. `[test]` **US-015.AC-1/AC-2 (HTTP)** — `GET /api/admin/db/report` with an admin token
   returns 200 and a per-table report body (status + missing/extra column lists) matching a
   seeded drift scenario.
2. `[test]` **US-016.AC-1 (HTTP)** — `POST /api/admin/db/tables/{name}/create` on a missing
   table succeeds and a subsequent `GET /report` shows it `ok`; on a name not in metadata
   returns 400.
3. `[test]` **US-017.AC-1/AC-2 (HTTP)** — `POST /api/admin/db/tables/{name}/sync` on a
   drifted table succeeds and a subsequent `GET /report` shows it `ok`.
4. `[test]` **US-018.AC-1 (HTTP)** — `GET /api/admin/db/export` returns 200, a zip media
   type, a `Content-Disposition: attachment` header, and non-empty zip bytes.
5. `[test]` **US-019.AC-1 (HTTP)** — `POST /api/admin/db/import` with a valid multipart
   `file` export restores its data (verified via a follow-up read).
6. `[test]` **US-019.AC-2 (HTTP)** — importing the same export twice via the endpoint
   produces no duplicate data.
7. `[test]` **US-019.AC-3 (HTTP)** — `POST /api/admin/db/import` with corrupt `file` bytes
   returns 400 and leaves the DB unchanged.
8. `[test]` **US-020.AC-1 (HTTP)** — `POST /api/admin/db/vector/rebuild` returns 200 (count
   / status) with a valid embedding designation.
9. `[test]` **D5/D7 (gating)** — each of the six endpoints with an `author`-role token
   returns 403; with an `admin`-role token returns its success status.
