# Step 005 — step-specific context

D5, the admin-gating pattern, and the `DbAdminError.case` → status map are in `context.md`.

Narrow to this step:

- **Router pattern to mirror** — `docs/plans/006.llm-server-connections/004.admin-routes-
  wiring.md`: `APIRouter(prefix="/api/admin/...")`, every endpoint
  `Depends(require_role(admin))`, HTTP-only, static-before-param ordering, one
  `app.include_router(...)` in `main.py`. `require_role(admin)` and the role ladder come
  from `services.auth` (006/005).
- **Static-before-param ordering matters here** — `/report`, `/export`, `/import`,
  `/vector/rebuild` must be declared before `/tables/{name}/create` and
  `/tables/{name}/sync` so no static segment is captured as a `{name}`. (`/tables/{name}/…`
  paths are themselves distinct from the static roots, but keep the declaration order
  explicit.)
- **Download response** — the export endpoint returns raw zip bytes, not JSON. Use a
  `Response`/`StreamingResponse` with a zip media type and
  `Content-Disposition: attachment; filename=...zip`. This is the first non-JSON admin
  response; the frontend reads it as a blob (step 006).
- **Multipart import** — accept `UploadFile` field named `file` (matches
  `POST /api/auth/setup/import` from `docs/plans/003.first-run-bootstrap/004.setup-routes-
  schemas.md`); `await file.read()` for the bytes, then call `db_admin.import_database`.
  Requires `python-multipart` (already a backend dependency per `docs/architecture/
  backend.md`).
- **No new schemas file needed** — request/response DTOs are the report DTO from
  `models/schemas/db_admin.py` (step 001) plus primitive path params; the rebuild endpoint
  returns the service's count/status shape. If a small response wrapper is needed for the
  rebuild count, the skeleton adds it to `models/schemas/db_admin.py` — flag to skeleton
  rather than inventing a new module here.
- **Tests** use the in-process `httpx.AsyncClient` over `ASGITransport` harness
  (`docs/architecture/backend.md`), the temp-DB fixture, and admin/author tokens minted the
  way 006's admin-route tests do. Seed drift/missing scenarios via raw `ALTER` / omitted
  tables as in steps 001–002.
