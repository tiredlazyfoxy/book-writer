# Step 007 — Admin SPA Database page + nav

## Goal
Give the Admin SPA a `Database` section: a consistency table with per-row create/sync
actions and drift column lists, plus export / import / rebuild controls, wired into the nav
and route table.

## Source files
frontend/src/admin/pages/DatabasePage.tsx
frontend/src/admin/pages/databasePageState.ts
frontend/src/admin/routes.tsx
frontend/src/admin/App.tsx

## Test files
None — every DoD item is `[manual/live]` (no frontend test runner exists; see `context.md`).

## Interface intent
- **`src/admin/pages/databasePageState.ts`** — `DatabasePageState` (`makeAutoObservable`)
  holding **only** the report async trio `report` / `reportStatus` / `reportError` (no
  effectful methods, per the MobX rules); plus external effect functions `(state, …,
  signal)` with `runInAction`:
  - **`loadReport`** — fetch `getConsistencyReport` + set the trio.
  - **`createTableAction`** — call `createTable(name)` then reload the report.
  - **`syncTableAction`** — call `syncTable(name)` then reload the report.
  - **`importAction`** — call `importDatabase(file)`; on success reload the report; on
    rejection (refusal) surface the error to the page (a status/error field the page reads).
  - **`rebuildAction`** — call `rebuildIndex()`; surface its count/status result.
  - (Export is a fire-and-forget `dbApi.exportDatabase()` triggered from an inner handler;
    it needs no trio.)
- **`src/admin/pages/DatabasePage.tsx`** — `observer` page component: owns the state via
  `useState(() => new DatabasePageState())`, a page-level `useEffect` that loads the report
  on mount and aborts on unmount. Renders a consistency **table** — one row per table with an
  `ok`/`drift`/`missing` **badge**; `drift` rows list their `missing_columns` /
  `extra_columns`; `missing` rows show a **Create** action (`createTableAction`); `drift`
  rows show a **Sync** action (`syncTableAction`). Above/beside the table: an **Export**
  button (`exportDatabase`), an **Import** control (file picker → `importAction`, with the
  refusal surfaced), and a **Rebuild** button (`rebuildAction`, showing the resulting
  count/status). Inner handlers close over `state`; no `useCallback`/`useMemo`; modal/target
  and file-input flags are component-local `useState`.
- **`src/admin/routes.tsx`** — add the `/admin/database` route pointing at `DatabasePage`
  (keep the existing users + llm-servers routes).
- **`src/admin/App.tsx`** — grow the nav to `Users | LLM Servers | Database`; keep the
  minimal local layout and the mount-time token gate. Do **not** build a heavyweight shared
  sidebar framework.

## Definition of done
1. `[manual/live]` **US-015.AC-1 (UI)** — the nav's `Database` link reaches a page whose
   table shows every table with an `ok` / `drift` / `missing` badge (from
   `getConsistencyReport`).
2. `[manual/live]` **US-015.AC-2 (UI)** — a `drift` row displays its `missing_columns` and
   `extra_columns`.
3. `[manual/live]` **US-016.AC-1 (UI)** — a `missing` row's Create action calls
   `createTable` and, after the report reloads, the row shows `ok`.
4. `[manual/live]` **US-017.AC-1/AC-2 (UI)** — a `drift` row's Sync action calls `syncTable`
   and, after reload, the row shows `ok`.
5. `[manual/live]` **US-018.AC-1 (UI)** — the Export button triggers a database file
   download (`exportDatabase`).
6. `[manual/live]` **US-019.AC-1/AC-3 (UI)** — the Import control uploads a chosen file via
   `importDatabase`; a valid export reloads the report with new data; a refused (400) import
   surfaces an error and does not claim success.
7. `[manual/live]` **US-020.AC-1 (UI)** — the Rebuild button calls `rebuildIndex` and shows
   the resulting count/status.
8. `[manual/live]` **D7 (MobX conventions)** — the page owns `DatabasePageState` (report
   trio only, `makeAutoObservable`, no effectful methods); loads/actions run through
   external `(state, …, signal)` functions with `runInAction`; page-level `useEffect` loads
   on mount and aborts on unmount; every component is `observer`-wrapped; all HTTP goes
   through `api/db.ts`. `npm run build` passes with no `any`.
