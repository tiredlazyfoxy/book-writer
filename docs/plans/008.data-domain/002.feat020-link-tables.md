# Step 002 — FEAT-020 link tables (mode_tool + subagent_tool + mode_subagent)

## Goal

Add the three FEAT-020 selection/link tables — surrogate snowflake PK plus a
composite `UniqueConstraint` on the natural pair (first-of-kind) — each with its
session-free `db/` module, JSONL codec pair, `TABLE_REGISTRY` tuple, and model
registration.

## Interface intent

- **`ModeTool` model** (`models/mode_tool.py`, table `mode_tool`): snowflake PK
  `id`; `mode_key` FK → `assistant_modes.key`; `tool_name` string; composite
  `UniqueConstraint(mode_key, tool_name)`.
- **`SubagentTool` model** (`models/subagent_tool.py`, table `subagent_tool`):
  snowflake PK `id`; `sub_agent_id` FK → `sub_agents.id`; `tool_name` string;
  composite `UniqueConstraint(sub_agent_id, tool_name)`.
- **`ModeSubagent` model** (`models/mode_subagent.py`, table `mode_subagent`):
  snowflake PK `id`; `mode_key` FK → `assistant_modes.key`; `sub_agent_id` FK →
  `sub_agents.id`; composite `UniqueConstraint(mode_key, sub_agent_id)`.
- **`db/mode_tools.py`**: `create`, `get_by_id`, `list_by_mode(mode_key)`.
- **`db/subagent_tools.py`**: `create`, `get_by_id`,
  `list_by_sub_agent(sub_agent_id)`.
- **`db/mode_subagents.py`**: `create`, `get_by_id`, `list_by_mode(mode_key)`.
- **Codecs** in `db_import_export.py`: a pair per table — `id` string /
  string-or-number; `mode_key` passed through verbatim as a string; FK int ids
  string/parsed; `tool_name` string. Register the three tuples in the order
  `mode_tools`, `subagent_tools`, `mode_subagents`, immediately after
  `sub_agents` and before any book-domain entry.
- **`_register_models()`**: add imports for `app.models.mode_tool`,
  `app.models.subagent_tool`, `app.models.mode_subagent`.

## Definition of done

1. **[test]** `mode_tool` codec round-trip: `id` string↔int; `mode_key` verbatim
   string; `tool_name` preserved.
2. **[test]** `subagent_tool` codec round-trip: `id` and `sub_agent_id`
   string↔int; `tool_name` preserved.
3. **[test]** `mode_subagent` codec round-trip: `id` and `sub_agent_id`
   string↔int; `mode_key` verbatim string.
4. **[test]** DB round-trip each table: `create` then `get_by_id` returns an
   equal row; `list_by_mode(mode_key)` returns exactly a mode's `mode_tool` /
   `mode_subagent` rows; `list_by_sub_agent(sub_agent_id)` returns exactly a
   sub-agent's `subagent_tool` rows.
5. **[test]** Composite unique enforced: inserting a second row with the same
   natural pair — `(mode_key, tool_name)` / `(sub_agent_id, tool_name)` /
   `(mode_key, sub_agent_id)` — is rejected by the DB.
6. **[test]** Registry: the three tables appear in canonical order
   (`mode_tools`, `subagent_tools`, `mode_subagents`), each after `sub_agents`,
   and the tablename sequence equals the canonical order restricted to the
   tables present so far.
7. **[test]** Schema present / drift-clean: after `init_db()`, the three tables
   exist in `SQLModel.metadata` and the FEAT-005 consistency report is clean.
