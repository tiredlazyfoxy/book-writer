## Interface intent

- **`Chapter` model** (`models/chapter.py`, table `chapters`): snowflake PK `id`;
  `book_id` FK → `books.id`; `ordinal` int; `title`; `state` enum {`planned`,
  `open`, `closing`, `closed`}; `sketch`; `text`; nullable `summary`; nullable
  `summary_status` enum {`draft`, `approved`, `stale`}; nullable `system_prompt`;
  `version` int default 1; `created_at` / `modified_at`. Two `str, enum.Enum`
  classes in this module.
- **`db/chapters.py`**: `create`, `get_by_id`, `list_by_book(book_id)`.
- **Codec** in `db_import_export.py`: a `Chapter` pair — `state` via
  `.value` / `E(...)`; nullable `summary_status` emitted as `e.value if e else
  None` and parsed as `E(x) if x else None`; nullable `summary` /
  `system_prompt` and `version` int passed through. Register `("chapters", ...)`
  immediately after `book_members`, before `chapter_changes`.
- **`_register_models()`**: add import for `app.models.chapter`.
