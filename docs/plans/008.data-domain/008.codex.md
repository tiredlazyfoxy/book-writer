## Goal

Add `CodexEntry` (character / location / fact; `name` nullable for facts) and
its history row `CodexEntryVersion` — each with its session-free `db/` module,
JSONL codec pair, `TABLE_REGISTRY` tuple, and model registration. **No vector /

## Interface intent

- **`CodexEntry` model** (`models/codex_entry.py`, table `codex_entries`):
  snowflake PK `id`; `book_id` FK → `books.id`; `kind` enum {`character`,
  `location`, `fact`}; nullable `name` string; `body`; `archived` bool default
  false; `author_id` FK → `users.id` (**required**, the original creator);
  `modified_by` FK → `users.id` (**nullable**, the author of the last version —
  maintained by the feature-013 service, declared and round-tripped only here);
  `created_at` / `modified_at`. One `str, enum.Enum` class.
- **`CodexEntryVersion` model** (`models/codex_entry_version.py`, table
  `codex_entry_versions`): snowflake PK `id`; `entry_id` FK → `codex_entries.id`;
  nullable `name`; `body`; `kind` enum (same kind enum, content as it stood);
  `author_id` FK → `users.id`; `generation` non-null int (1-based sequence /
  generation number of this version within its entry — maintained by the
  service, declared and round-tripped only here); `created_at`.
- **`db/codex_entries.py`**: `create`, `get_by_id`, `list_by_book(book_id)`.
- **`db/codex_entry_versions.py`**: `create`, `get_by_id`,
  `list_by_entry(entry_id)`.
- **Codecs** in `db_import_export.py`: a `CodexEntry` pair (`kind` via `.value`
  / `E(...)`; nullable `name` passed through including the null-for-fact case;
  `archived` bool; `author_id` emitted/parsed string↔int; `modified_by`
  emitted/parsed nullable string↔int, i.e. `None` when null) and a
  `CodexEntryVersion` pair (`generation` a plain int emitted/parsed as-is).
  Register `("codex_entries", ...)` then `("codex_entry_versions", ...)` at their
  canonical position — **between `chapter_note_changesets` and `flags`** (see
  registry note).
- **`_register_models()`**: add imports for `app.models.codex_entry` and
  `app.models.codex_entry_version`.
- **No `db/vector.py` change, no `VECTOR_SOURCE_REGISTRY` entry** — `codex_entries`
  is an ordinary data table here; its vector indexing is deferred.
