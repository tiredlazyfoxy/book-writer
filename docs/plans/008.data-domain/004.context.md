# Step 004 — step-specific context

Field specs from `domain-book.md`. Shared conventions in `context.md`.

## `Book` (table `books`) — `domain-book.md` → "Book"

**Realizes:** FEAT-006 (UC-021..025), FEAT-007 (UC-026..030), FEAT-011 (UC-044),
FEAT-015.

| Field | Type / notes |
|---|---|
| `id` | snowflake PK |
| `title` | display title |
| `description` | free text, may be empty |
| `owner_id` | FK → `users.id`. Exactly one owner (a plain non-null FK; "exactly one" is structural, no extra constraint) |
| `collaboration_mode` | enum {`free`, `proposal`} |
| `visibility` | enum {`private`, `public`} |
| `state` | enum {`active`, `archived`, `quarantined`, `destroyed`} — one lifecycle column, not two booleans |
| `moderation_reason` | nullable text; null on an `active` book |
| `moderated_by` | nullable FK → `users.id`; null until moderated |
| `moderated_at` | nullable datetime; null until moderated |
| `system_prompt` | book-wide prompt (book-shaping state; no product requirement yet — divergence 3) |
| `active_notes` | materialised live state-note set, free text |
| `created_at` / `modified_at` | timestamps |

- The moderation triple and the enum values `quarantined` / `destroyed` /
  `archived` **land now, nullable/unused** — Stage-6 behaviour, per the
  Stage-4-columns rule in `context.md`. `destroyed` is a tombstone state, not a
  deleted row.
- No `genre` / `target_length` / `language` / cover — deliberately not invented.

## `BookMember` (table `book_members`) — `domain-book.md` → "BookMember"

| Field | Type / notes |
|---|---|
| `id` | snowflake PK |
| `book_id` | FK → `books.id` |
| `user_id` | FK → `users.id` |
| `role` | co-author role marker |
| `created_at` | timestamp (this entity carries only one timestamp) |

Unique `(book_id, user_id)` via `__table_args__` — carries "one membership per
user per book". The owner is **not** a `BookMember` row (ownership is
`Book.owner_id`); readers have no row at all.

`mode_subagents` tuple (end of the FEAT-020 config block), before `chapters`.
