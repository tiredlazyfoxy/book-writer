# Step 001 — FEAT-020 config core (AssistantMode + SubAgent)

## Goal

Add the two admin-editable FEAT-020 config tables — `AssistantMode`
(natural-key PK, first-of-kind) and `SubAgent` (snowflake PK, nullable model
pair) — each with its session-free `db/` module, JSONL codec pair,
`TABLE_REGISTRY` tuple, and model registration.

## Interface intent

- **`AssistantMode` model** (`models/assistant_mode.py`, table
  `assistant_modes`): natural-key primary key `key` (string), nullable
  `system_prompt` text, `created_at` / `modified_at` (nullable, app-set). No
  snowflake, no `generate_id`.
- **`SubAgent` model** (`models/sub_agent.py`, table `sub_agents`): snowflake PK
  `id`; `name` unique + indexed; `system_prompt` text; `disabled` bool default
  false; nullable `llm_server_id` FK → `llm_servers.id`; nullable `model_name`
  string; `created_at` / `modified_at`. Both model fields declared nullable
  independently — the "move together" invariant is a service rule for feature
  012, **not** enforced here.
- **`db/assistant_modes.py`**: session-free `create(row)` returning the row,
  `get_by_id(key)` returning the row or None (lookup by the `key` PK), and
  `list_all()` returning every mode row. (Step 003 adds `seed_default_modes` to
  this same module.)
- **`db/sub_agents.py`**: session-free `create(row)` and `get_by_id(id)`.
- **Codecs** in `db_import_export.py`: an `AssistantMode` pair emitting/parsing
  `key` **verbatim** (never `int()`); a `SubAgent` pair emitting `id` as string
  / parsing string-or-legacy-number, `disabled` as bool, nullable
  `llm_server_id` / `model_name` / timestamps passed through. Register the two
  tuples in `TABLE_REGISTRY` **immediately after `llm_servers`** (positions 3
  and 4), before any book-domain entry.
- **`_register_models()`**: add imports for `app.models.assistant_mode` and
  `app.models.sub_agent`.

## Definition of done

1. **[test]** `AssistantMode` codec round-trip: `to_dict(row)` then
   `from_dict(...)` reconstructs every field; `key` is emitted and parsed
   **verbatim** — assert a key such as `edit-character` survives unchanged and
   is **not** coerced through `int`; nullable `system_prompt` (None and set) and
   isoformat timestamps preserved.
2. **[test]** `SubAgent` codec round-trip: `id` emitted as a string then parsed
   back to the same int; `disabled` bool preserved; nullable `llm_server_id` /
   `model_name` preserved in both the both-null and both-set shapes; timestamps
   via isoformat.
3. **[test]** `db/assistant_modes.py` round-trip: `create(row)` then
   `get_by_id(row.key)` returns an equal row; `list_all()` includes it.
4. **[test]** `db/sub_agents.py` round-trip: `create(row)` then
   `get_by_id(row.id)` returns an equal row.
5. **[test]** Registry: `assistant_modes` and `sub_agents` appear in
   `TABLE_REGISTRY`, `llm_servers` precedes `sub_agents`, and the tablename
   sequence equals the canonical order restricted to the tables present so far.
6. **[test]** Schema present / drift-clean: after `init_db()`, `assistant_modes`
   and `sub_agents` exist in `SQLModel.metadata` and the FEAT-005 consistency
   report is clean.
