# Step 006 — ChapterChange + ChapterTextRevision

## Goal

Add the unified chapter write record `ChapterChange` and the pre-apply snapshot
`ChapterTextRevision` — each with its session-free `db/` module, JSONL codec
pair, `TABLE_REGISTRY` tuple, and model registration.

## Interface intent

- **`ChapterChange` model** (`models/chapter_change.py`, table
  `chapter_changes`): snowflake PK `id`; `chapter_id` FK → `chapters.id`;
  `author_id` FK → `users.id`; `placement_kind` enum {`append`, `range`};
  nullable `line_from` int; nullable `line_to` int; `base_version` int; `text`;
  `status` enum {`pending`, `applied`, `rejected`}; nullable `applied_at`;
  nullable `applied_by` FK → `users.id`; `created_at`. Two `str, enum.Enum`
  classes in this module.
- **`ChapterTextRevision` model** (`models/chapter_text_revision.py`, table
  `chapter_text_revisions`): snowflake PK `id`; `chapter_id` FK → `chapters.id`;
  `applied_change_id` FK → `chapter_changes.id`; `text_before`; `applied_by`
  FK → `users.id`; `applied_at`.
- **`db/chapter_changes.py`**: `create`, `get_by_id`,
  `list_by_chapter(chapter_id)`.
- **`db/chapter_text_revisions.py`**: `create`, `get_by_id`,
  `list_by_chapter(chapter_id)`.
- **Codecs** in `db_import_export.py`: a `ChapterChange` pair (both enums;
  nullable `line_from` / `line_to` / `applied_at` / `applied_by` passed through)
  and a `ChapterTextRevision` pair. Register `("chapter_changes", ...)` then
  `("chapter_text_revisions", ...)` immediately after `chapters`, before
  `chapter_note_changesets`.
- **`_register_models()`**: add imports for `app.models.chapter_change` and
  `app.models.chapter_text_revision`.

## Definition of done

   `author_id` string↔int; `placement_kind` and `status` via `.value` /
   `E(...)`; nullable `line_from` / `line_to` preserved in both the range shape
   (ints set) and the append shape (both null); nullable `applied_at` /
   `applied_by` preserved (null before apply, set after); `base_version` int and
   isoformat `created_at` preserved.
2. **[test]** `ChapterTextRevision` codec round-trip: `id` / `chapter_id` /
   `applied_change_id` / `applied_by` string↔int; `text_before` and isoformat
   `applied_at` preserved.
3. **[test]** DB round-trip: `create` then `get_by_id` returns an equal row for
   both tables; `list_by_chapter(chapter_id)` returns exactly a chapter's rows
   for each.
4. **[test]** Registry: `chapter_changes` then `chapter_text_revisions` present,
   each after `chapters`, and the tablename sequence equals the canonical order
   restricted to the tables present so far.
5. **[test]** Schema present / drift-clean: after `init_db()`, both tables exist
   in `SQLModel.metadata` and the FEAT-005 consistency report is clean.
