## Goal

## Interface intent

- **`ChapterNoteChangeset` model** (`models/chapter_notes.py`, table
  `chapter_note_changesets`): snowflake PK `id`; `chapter_id` FK → `chapters.id`
  with single-column `Field(unique=True)` (one changeset per chapter); `added`;
  `modified`; `deleted` (free text each); nullable `status` enum {`draft`,
  `approved`, `stale`}; `created_at` / `modified_at`. One `str, enum.Enum` class.
- **`Flag` model** (`models/flag.py`, table `flags`): snowflake PK `id`;
  `chapter_id` FK → `chapters.id`; `origin` enum {`check`, `person`}; `comment`;
  `status` enum {`open`, `resolved`}; `created_by` FK → `users.id`;
  `created_at`; nullable `resolved_by` FK → `users.id`; nullable `resolved_at`.
  Two `str, enum.Enum` classes.
- **`db/chapter_note_changesets.py`**: `create`, `get_by_id`,
  `get_by_chapter(chapter_id)` returning the single row or None (unique
  chapter).
- **`db/flags.py`**: `create`, `get_by_id`, `list_by_chapter(chapter_id)`.
- **Codecs** in `db_import_export.py`: a `ChapterNoteChangeset` pair (nullable
  `status` via `e.value if e else None` / `E(x) if x else None`) and a `Flag`
  pair (both enums; nullable `resolved_by` / `resolved_at` passed through).
  Register `("chapter_note_changesets", ...)` immediately after
  `chapter_text_revisions`; register `("flags", ...)` at the **canonical `flags`
  position** — see the registry note below.
- **`_register_models()`**: add imports for `app.models.chapter_notes` and
  `app.models.flag`.
