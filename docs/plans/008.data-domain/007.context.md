# Step 007 — step-specific context

Field specs from `domain-continuity.md`. Shared conventions in `context.md`.

## `ChapterNoteChangeset` (table `chapter_note_changesets`) — "Notes"

**Realizes:** FEAT-012 (UC-047..052), FEAT-016.

| Field | Type / notes |
|---|---|
| `id` | snowflake PK |
| `chapter_id` | FK → `chapters.id`, **`Field(unique=True)`** — one changeset per chapter (single-column unique, not a composite) |
| `added` / `modified` / `deleted` | free text, one field per operation |
| `status` | nullable enum {`draft`, `approved`, `stale`} |
| `created_at` / `modified_at` | timestamps |

The whole table and its `status` **land now, nullable/unused** — Stage-4
behaviour (Stage-4-columns rule in `context.md`). A separate 1:1 table rather
than three columns on `Chapter` keeps the hot chapter row narrow.

## `Flag` (table `flags`) — "Flag"

**Realizes:** FEAT-016 (UC-066..068, UC-080); US-076.

| Field | Type / notes |
|---|---|
| `id` | snowflake PK |
| `chapter_id` | FK → `chapters.id` |
| `origin` | enum {`check`, `person`} |
| `comment` | the flag's text |
| `status` | enum {`open`, `resolved`} |
| `created_by` | FK → `users.id` |
| `created_at` | timestamp |
| `resolved_by` | nullable FK → `users.id`; null until resolved |
| `resolved_at` | nullable datetime; null until resolved |

**The internal name stays `flag`** — the table, db module and (future) DTOs are
`flag`; the author-facing UI term "warning" is not this feature's concern.

## Registry position — the `flags` interleave

`chapter_note_changesets` slots immediately after `chapter_text_revisions`.
`flags` slots at its canonical position **after `codex_entry_versions`** — but
the codex tables are added in step 008, *after* this step. So at this step's
time, `flags` is inserted right after `chapter_note_changesets` (the current end
of the registry), which satisfies the canonical-restricted invariant because
codex is absent. **Step 008 then inserts the codex tables *between*
`chapter_note_changesets` and `flags`**, restoring the full canonical order. Do
not append `flags` blindly at the very end — put it directly after
`chapter_note_changesets` so step 008 can slot codex in front of it.
