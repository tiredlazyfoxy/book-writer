# Step 004 — Book + BookMember

## Goal

Add the book aggregate root `Book` (owner FK, three enums, moderation fields
landing now nullable) and `BookMember` (composite unique) — each with its
session-free `db/` module, JSONL codec pair, `TABLE_REGISTRY` tuple, and model
registration.

## Interface intent

- **`Book` model** (`models/book.py`, table `books`): snowflake PK `id`; `title`;
  `description`; `owner_id` FK → `users.id`; `collaboration_mode` enum
  {`free`, `proposal`}; `visibility` enum {`private`, `public`}; `state` enum
  {`active`, `archived`, `quarantined`, `destroyed`}; nullable
  `moderation_reason`; nullable `moderated_by` FK → `users.id`; nullable
  `moderated_at`; `system_prompt`; `active_notes`; `created_at` / `modified_at`.
  Three `str, enum.Enum` classes defined in this module.
- **`BookMember` model** (`models/book_member.py`, table `book_members`):
  snowflake PK `id`; `book_id` FK → `books.id`; `user_id` FK → `users.id`;
  `role`; `created_at`; composite `UniqueConstraint(book_id, user_id)`.
- **`db/books.py`**: `create`, `get_by_id`.
- **`db/book_members.py`**: `create`, `get_by_id`, `list_by_book(book_id)`.
- **Codecs** in `db_import_export.py`: a `Book` pair (three enums via
  `.value` / `E(...)`; nullable moderation fields and timestamps passed
  through) and a `BookMember` pair. Register `("books", ...)` then
  `("book_members", ...)` immediately after `mode_subagents` and before
  `chapters`.
- **`_register_models()`**: add imports for `app.models.book` and
  `app.models.book_member`.

## Definition of done

1. **[test]** `Book` codec round-trip: `id` string↔int; `collaboration_mode` /
   `visibility` / `state` each via `.value` on emit and `E(...)` on parse;
   nullable `moderation_reason` / `moderated_by` / `moderated_at` preserved in
   both the all-null (active book) and all-set (moderated book) shapes;
   `system_prompt` / `active_notes` and isoformat timestamps preserved.
2. **[test]** `BookMember` codec round-trip: `id` / `book_id` / `user_id`
   string↔int; `role` and timestamp preserved.
3. **[test]** DB round-trip: `create` then `get_by_id` returns an equal row for
   both tables; `list_by_book(book_id)` returns exactly a book's members.
4. **[test]** Composite unique enforced: a second `BookMember` with the same
   `(book_id, user_id)` is rejected by the DB.
5. **[test]** Registry: `books` then `book_members` present, each after
   `mode_subagents`, and the tablename sequence equals the canonical order
   restricted to the tables present so far.
6. **[test]** Schema present / drift-clean: after `init_db()`, `books` and
   `book_members` exist in `SQLModel.metadata` and the FEAT-005 consistency
   report is clean.
