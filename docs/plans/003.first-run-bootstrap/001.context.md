## Substrate this step binds to (from 001-scaffold — see `context.md`)
- `db/engine.py` `get_standalone_session()` is the **only** session primitive the
  `db/users` module may use; it raises if the engine is uninitialized.

  ORM row past the module boundary.

## Table registration for this step's tests
The `User` SQLModel class registers on `SQLModel.metadata` **at import time**
(when its module is imported). This step's tests import `app.db.users`, which
imports `app.models.user` — so the shared `conftest` temp-DB fixture's
`init_db()` (`create_all`) builds the `users` table without needing the engine
model-registration hook. (Step 002 still adds the explicit hook import so
production startup does not rely on incidental imports.)

## `admin_exists` on a cold instance
For DoD-5 the `users` table may not exist. `admin_exists` must catch the
missing-table error (e.g. SQLAlchemy `OperationalError` "no such table") and
return `False`, never propagate. This is what lets the step-002 lifespan detect
"unconfigured" before any table is created.

## Auth-scheme facts (from `backend.md`, feature-wide — see `context.md`)
bcrypt hashing + per-user HS256 JWT with the user's own signing key. This step
builds only hash/verify/keygen/mint. No shared global secret exists.
