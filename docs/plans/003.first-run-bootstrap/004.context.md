## HTTP status mapping
`SetupError` → **HTTP 400** for every refusal (already-configured, short
password, mismatch, corrupt import). DoD-3 (`US-001.AC-2`) only requires a
non-200 4xx "refused"; 400 satisfies it. The route must not leak stack traces —
surface the `SetupError` message as the 400 detail.
