# 007 — Memos reach every sub-agent: the section rides on `ParentTurn`

## Goal

Give a delegated sub-agent the author's active memos by carrying step 006's already-rendered section on
`ParentTurn` and composing it with the sub-agent's own prompt — and nothing else — so parent and child
see an identical set from one database read.

```
backend/app/services/subagent_delegation.py
backend/app/services/chat_turn.py
backend/app/services/assistant_runtime.py
```

or chapter layer threads through — becomes DoD-2.

## Interface intent

**`backend/app/services/subagent_delegation.py`**

- **`ParentTurn` gains one field: the rendered memo section** (the same optional string step 006
  produces). It is the natural carrier — a frozen dataclass already flowing
  `chat_turn → resolve_turn_tools → build_delegation_tools → run_delegation → _delegate`, and
  `_delegate` is where `system=sub_agent.system_prompt` is today the sole uncomposed value.
- **`_delegate` composes the nested call's `system`** as the sub-agent's own prompt **plus the `MEMOS`
  section, and nothing else** — not the mode, author or chapter layers. It uses the **same composer**
  step 006 changed, so the section's label and separators are identical in the parent's prompt and the
  child's; it does not hand-assemble a second rendering.
- **This module performs no memos read.** It must not import `db/memos.py` and must not call the render
  function: the section arrives on `ParentTurn` or it does not arrive at all. Record the reasoning in
  the module or function docstring — one DB read per turn, and (the load-bearing half) parent and every
  sub-agent are guaranteed an **identical** set even if `create_memo` adds one mid-turn.
- Everything else is unchanged: the synthetic-tool derivation and its collision guard, the sub-agent's
  own tool allowlist, its own model resolution, its own `max_loops`, and the rule that **every
  delegation failure comes back to the parent as a short error string, never an exception**.

**`backend/app/services/chat_turn.py`** — pass the section rendered in step 006 into the `ParentTurn`
it already constructs. No second read, no re-render.

**`backend/app/services/assistant_runtime.py`** — in scope **only** for the pass-through: it hands the
`ParentTurn` to the delegation builder and may need its annotation or docstring updated to mention the
carried section. **Nothing about mode determination, `allowed_tool_names`, `resolve_turn_tools`'s rules
or `BASE_TOOL_NAMES` changes here** — `BASE_TOOL_NAMES` is step 008's.

## Definition of done

1. `[test]` (US-132.AC-2) A delegated sub-agent's nested system prompt contains the author's active
   memos, in the author's order.
2. `[test]` (US-132.AC-2) It contains **only** the sub-agent's own prompt and the `MEMOS` section — no
   base, mode, author or chapter layer threads through. (This replaces the existing
   prompt-alone assertion rather than contradicting its intent: the self-contained worker property is
   preserved for **behaviour**, while the author's standing **facts** are honoured.)
3. `[test]` (US-131.AC-3) Inactive and archived memos are absent from the sub-agent's prompt, exactly as
   they are from the parent's — the section is the same string.
4. `[test]` (UC-109 postcondition — no separate AC) With **no active memos**, the sub-agent's system is
   its own prompt alone, unchanged from today's behaviour: no empty section, no stray separator.
5. `[test]` *(architecture — `assistant-runtime.md` → "the memo section is rendered once")*
   `subagent_delegation.py` performs **no memos read of its own**: the section it uses is the one
   carried on `ParentTurn`, and the module reaches no memo data by any other path.
6. `[test]` (US-132.AC-2) Parent and child see an **identical** memo set within one turn — a memo
   created mid-turn does not appear in one and not the other.
7. `[test]` *(architecture — `assistant-runtime.md` → delegation failures)* Delegation failure behaviour
   is unchanged: a failing nested call still returns a **short error string** to the parent rather than
   raising, with a memo section present and absent alike.
