# 003 — Book create + list

## Goal

Deliver the book create endpoint (caller becomes owner) and the two list endpoints
(books I own, books shared with me), as a `/api/books` vertical slice with the
book-error-mapping pattern.

## Source files

backend/app/models/schemas/books.py
backend/app/services/books.py
backend/app/routes/books.py
backend/app/main.py

## Test files

backend/tests/routes/test_books.py

## Interface intent

- **Schemas (`models/schemas/books.py`, new)** — plain `BaseModel`s:
  - **`CreateBookRequest`** — the author's create input: `title`, `description`,
    `collaboration_mode`, `visibility`. (No state/prompt/notes — those are defaulted
    server-side.)
  - **`BookResponse`** — a book summary DTO for lists and create result: id and
    `owner_id` as **strings**, plus `title`, `description`, `collaboration_mode`,
    `visibility`, `state`, timestamps. No moderation internals.
  - **`BookListResponse`** — the list envelope `{ items: list[BookResponse] }`.
- **Service (`services/books.py`, new)**:
  - typed **`BookError`** + **`BookErrorReason`** enum (mirror `LlmServerError` /
    `LlmServerErrorReason`), and a private **`_to_response(book)`** hand-mapper
    (never dumps ORM).
  - **`create_book(request, caller)`** — builds a `Book` with the caller as
    `owner_id`, the requested mode/visibility, and defaults: `state = active`,
    `system_prompt = ""`, `active_notes = ""`, moderation fields null, timestamps set
    via `datetime.now(timezone.utc)`; persists via `db/books.create`; returns a
    `BookResponse`. **Creates no chapter skeleton** (deferred). Realizes UC-021.
  - **`list_owned(caller)`** — returns the caller's owned books via
    `db/books.list_by_owner`, mapped to `BookResponse`. Realizes UC-022.
  - **`list_shared(caller)`** — returns books where the caller is a co-author (not
    owner) via `db/books.list_shared`, mapped to `BookResponse`. Realizes UC-030.
- **Routes (`routes/books.py`, new)** — router owning `/api/books`, all guarded by
  `Depends(auth_service.get_current_user)` (author-scoped, **not** the admin gate);
  a module-level status dict + `_map_book_error` helper mapping `BookError` reasons
  to `HTTPException`:
  - **`POST /api/books`** (status 201) — create; body `CreateBookRequest`, returns
    `BookResponse`.
  - **`GET /api/books`** — the caller's owned books, returns `BookListResponse`.
  - **`GET /api/books/shared`** — the caller's shared books, returns
    `BookListResponse`. **Declared before** any `/{book_id}` route (added in step 4)
    so the static path wins.
- **Registration (`main.py`)** — one import + one `app.include_router(books.router)`.

## Definition of done

1. **[test]** `POST /api/books` with a valid token creates a book with the requested
   collaboration mode and visibility; the response reflects both. *(US-022.AC-1.)*
2. **[test]** `POST /api/books` sets the caller as the book's owner (response
   `owner_id` == caller's id). *(US-022.AC-2.)*
3. **[test]** A created book defaults to `state == active`. *(Realizes UC-021
   postcondition; no dedicated US-AC — record as create-default coverage.)*
4. **[test]** `POST /api/books` without a valid token → **401**. *(authorization.md
   → "Failure modes": no anonymous book surface; UC-021 precondition "author
   authenticated".)*
5. **[test]** `GET /api/books` returns exactly the books the caller owns and none
   owned by another author. *(US-023.AC-1.)*
6. **[test]** `GET /api/books/shared` returns exactly the books where the caller is a
   co-author and not the owner — excluding books they own. *(US-031.AC-1.)*
7. **[test]** Response DTO ids (`id`, `owner_id`) are JSON strings. *(API typing
   convention — snowflake as string; no dedicated US-AC.)*
8. **[manual/live]** `services/books.py` contains no `session` / `select` /
   `session.add`; the route layer holds no business logic (layer separation, read).
