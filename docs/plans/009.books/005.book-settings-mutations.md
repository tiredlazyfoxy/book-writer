# 005 — Book settings mutations

## Goal

Add every owner-only book mutation — archive/unarchive, transfer ownership, add/
remove co-author, set visibility — each gated by the matching `authz` capability on
the resolved `BookAccess`.

## Source files

backend/app/models/schemas/books.py
backend/app/services/books.py
backend/app/routes/books.py

## Test files

backend/tests/routes/test_book_settings.py

## Interface intent

- **Schemas (extend `models/schemas/books.py`)**:
  - **`TransferOwnershipRequest`** — the target user id (as string in, resolved to
    int) to become the new owner.
  - **`AddMemberRequest`** — the author-account user id to grant co-author access.
  - **`SetVisibilityRequest`** — the target visibility value.
  - Reuse `BookResponse` / `BookDetailResponse` for results (skeleton's call which
    each mutation returns).
- **Service (extend `services/books.py`)** — each takes the resolved `BookAccess`,
  calls `authz.require(access, <capability>)`, mutates via `db/books.update` /
  `db/book_members.create|delete`, sets `modified_at`, returns the updated view:
  - **`archive_book(access)`** — `require(archive_book)`; sets `state = archived`;
    preserves all content fields. Realizes UC-023 / US-024.AC-1, AC-2. **Does not**
    touch chapters (US-024.AC-4 deferred) and builds **no** write-refusal
    (US-024.AC-3 deferred).
  - **`unarchive_book(access)`** — `require(archive_book)`; sets `state = active`;
    the reversible return path (UC-023). Refuse if the book is not archived
    (`BookError`).
  - **`transfer_ownership(access, target_user_id)`** — `require(transfer_ownership)`;
    **only** if the target is a current co-author (a `BookMember` row exists) does it
    set `owner_id = target`; a non-member target is **refused** (`BookError`) — the
    resolved `_TBD_`. Realizes UC-024 / US-025.AC-1.
  - **`add_member(access, target_user_id)`** — `require(add_member)`; creates a
    `BookMember(role = co_author)` for the target; the unique `(book_id, user_id)`
    constraint means re-adding an existing member is a no-op/refusal (skeleton's
    call — surface as `BookError`, don't 500). Realizes UC-026 / US-027.AC-1.
  - **`remove_member(access, target_user_id)`** — `require(remove_member)`; deletes
    the membership via `db/book_members.delete`; a non-member target is refused
    (`BookError`, 404). Access ends immediately. Realizes UC-027 / US-028.AC-1. (No
    block/attribution cascade — nothing to cascade in 009; US-028.AC-2/AC-3
    deferred.)
  - **`set_visibility(access, visibility)`** — `require(set_visibility)`; sets
    `visibility`. Realizes UC-028 / US-029.AC-1, AC-2.
- **Routes (extend `routes/books.py`)** — all `Depends(book_access(book_id))`, map
  `BookAuthorizationError` → 403 and `BookError` → its status:
  - **`POST /api/books/{book_id}/archive`**, **`POST /api/books/{book_id}/unarchive`**
  - **`POST /api/books/{book_id}/transfer`** (body `TransferOwnershipRequest`)
  - **`POST /api/books/{book_id}/members`** (body `AddMemberRequest`)
  - **`DELETE /api/books/{book_id}/members/{user_id}`**
  - **`PATCH /api/books/{book_id}/visibility`** (body `SetVisibilityRequest`)

## Definition of done

1. **[test]** `POST /{book_id}/archive` by the owner sets `state` to `archived`.
   *(US-024.AC-1.)*
2. **[test]** After archiving, the book's content fields (title, description,
   system_prompt, active_notes) are unchanged. *(US-024.AC-2.)*
3. **[test]** `POST /{book_id}/unarchive` by the owner returns the book to
   `state == active` with content still intact (reversibility). *(US-024.AC-2 across
   the archive→unarchive round-trip; UC-023 reversible.)*
4. **[test]** `POST /{book_id}/transfer` to a current **co-author** makes that
   co-author the new owner (`owner_id` updated). *(US-025.AC-1.)*
5. **[test]** `POST /{book_id}/transfer` to a **non-member** is refused (4xx, no
   ownership change). *(US-025.AC-1 complement — resolved `_TBD_`: refuse.)*
6. **[test]** `POST /{book_id}/members` by the owner grants the target co-author
   access — the target subsequently resolves as a co-author (appears in the detail
   `members` list / can open the book). *(US-027.AC-1.)*
7. **[test]** `DELETE /{book_id}/members/{user_id}` by the owner ends that
   co-author's access — the removed user is refused (**404**) on the private book
   afterward. *(US-028.AC-1.)*
8. **[test]** `PATCH /{book_id}/visibility` to `public` lets a logged-in non-member
   open the reader projection (200 on `/read`). *(US-029.AC-1.)*
9. **[test]** `PATCH /{book_id}/visibility` to `private` refuses a logged-in
   non-member (**404** on `/read`). *(US-029.AC-2.)*
10. **[test]** Every mutation refuses a **co-author** caller with **403** (owner-only
    matrix) — archive, transfer, add-member, remove-member, set-visibility.
    *(Owner-only rows of US-024.AC-1, US-025.AC-1, US-027.AC-1, US-028.AC-1,
    US-029.AC-1.)*
11. **[manual/live]** US-024.AC-3 (archived refuses writes), US-024.AC-4 (frozen open
    chapter), US-028.AC-2/AC-3 (block/attribution survival) are **not** built here —
    deferred per `context.md`; the archived book still resolves and reads.
