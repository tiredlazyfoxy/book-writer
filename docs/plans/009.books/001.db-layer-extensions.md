# 001 — DB-layer extensions

## Goal

Add the session-free `db/` query and mutation functions the book slice needs
(update, owner/shared/member lookups, delete), and promote `BookMember.role` from a
plain string to a single-value `MemberRole` enum.

## Interface intent

- **`MemberRole` enum** (`models/book_member.py`) — a `(str, Enum)` with the single
  value `co_author`, mirroring the other book enums. Retype `BookMember.role` from
  plain `str` to `MemberRole`. This is the co-authorship marker; the owner still has
  no `BookMember` row.
- **`db/books.py` additions** (session-free; sessions created internally; ORM types
  never leak):
  - **`update`** — persist changes to an existing `Book` row (used by transfer,
    archive/unarchive, visibility). Follows the 008/`llm_servers` add/commit/refresh
    convention; the caller passes the mutated `Book`.
  - **`list_by_owner`** — return all `Book` rows whose `owner_id` matches, ordered
    deterministically. Enables the "books I own" list.
  - **`list_shared`** — return all `Book` rows where the given user is a
    `BookMember` (co-author) and is **not** the owner. Enables the "shared with me"
    list. (Join through `book_members`; exclude any book the user owns.)
- **`db/book_members.py` additions** (session-free):
  - **`get_by_book_and_user`** — return the `BookMember` row for a `(book_id,
    user_id)` pair or `None`. The role-resolution primitive the authz resolver uses.
  - **`delete`** — remove the membership for a `(book_id, user_id)` pair; report
    whether a row was removed (so the service can 404 a non-member removal). Decide
    the exact key/return with the skeleton, but it must key on `(book_id, user_id)`,
    not the surrogate member id.
  - **`list_by_user`** — return every `BookMember` row for a user (support for
    `list_shared`; may be used internally by `list_shared` or by the service).
- **JSONL codec (`services/db_import_export.py`)** — touch the existing
  `_book_member_to_dict` / `_dict_to_book_member` **only if** the `MemberRole` retype
  breaks round-trip. If touched, serialise via `.value` and rebuild via
  `MemberRole(...)`. If a `(str, Enum)` role round-trips unchanged, leave the codec
  as-is and record that in the step's Files Changed.

## Definition of done

1. **[test]** `MemberRole` is a `(str, Enum)` with value `co_author`, and
   `BookMember.role` is typed as `MemberRole`; a member row created and read back
   preserves the enum value. *(data-integrity / typing discipline; underpins
   US-027.AC-1 co-author role marker — no dedicated US-AC.)*
2. **[test]** A `Book` + `BookMember` round-trip through the JSONL export→import
   codec preserves `role` as `MemberRole.co_author`. *(CLAUDE.md → "DB
   Import/Export": every persistent model round-trips; no dedicated US-AC.)*
3. **[test]** `db/books.update` persists field changes to an existing row and a
   subsequent `get_by_id` returns the new values. *(Enables US-024.AC-1,
   US-025.AC-1, US-029.AC-1 at the data layer.)*
4. **[test]** `db/books.list_by_owner` returns exactly the books whose `owner_id`
   matches the given user and none owned by others. *(Enables US-023.AC-1.)*
5. **[test]** `db/books.list_shared` returns exactly the books where the user is a
   co-author and not the owner — excluding books they own and books they have no
   membership in. *(Enables US-031.AC-1.)*
6. **[test]** `db/book_members.get_by_book_and_user` returns the matching row for a
   member pair and `None` for a non-member pair. *(Enables the authz role resolver;
   no dedicated US-AC.)*
7. **[test]** `db/book_members.delete` removes the membership for a `(book_id,
   user_id)` pair and reports removal; a second delete of the same pair reports
   no-op. *(Enables US-028.AC-1.)*
8. **[test]** `db/book_members.list_by_user` returns every membership row for a
   user. *(Supports US-031.AC-1; no dedicated US-AC.)*
9. **[manual/live]** No `session` / `select` / `session.add` leaks out of `db/`;
   the layer separation holds (verified by reading, not a test).

## Dependencies

None (extends the 008-delivered data layer).
