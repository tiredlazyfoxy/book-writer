## Why the subject model changes at all

`frontend-workspace.md`'s content-pane editability table says a `planned` chapter is **read-only**,
citing US-097.AC-1. That criterion is about the chapter's **text**. The skeleton feature makes the
sketch of a `planned` chapter editable (UC-033, US-034.AC-1) — the exact opposite window from the
body, which is writable only while `open`.

So the amendment is: **the subject is not "editable" or "read-only" wholesale — it is editable by
region.** The table already has the vocabulary for that (`EditableRegion`), it just had no chapter row
using it. `outcome.md` carries the doc change.

DoD-13 exists because widening editability and widening the *write path* are different things: a
shared-canvas write into a `planned` chapter's body must still be refused, and that refusal is
`checkWritePermission`'s, not `resolveEditability`'s.

## The prompt editor's shape is `021`'s, copied

`frontend/src/work/pages/bookStatePageState.ts` is the direct model: alongside its own trios it

prompt editor exactly as `021` shipped it; this page gets its own. `bookStatePageState.ts` and
`BookStatePage.tsx` are deliberately **not** in this step's source list.

## The prompt is stored and served, and composed into nothing

D7. The chapter prompt this page writes is not read by any assistant turn — wiring it into composition
needs "which chapter is this turn about", which is undesigned FEAT-013 context assembly, and is
`015.chapter-writing-free-mode`'s. **Do not write copy on this page promising the prompt affects the
assistant right now.** The honest line is that the prompt is the caller's own and not shared with
co-authors (DoD-10), which is true today.

## No restore buffer

`frontend-workspace.md`'s draft-until-saved restore buffer (UC-092) exists for large content-pane
artifacts whose loss is expensive — chapter bodies and codex entries — and keys off a version token.
Neither field here has one: the sketch is explicitly last-write-wins with no version (D6), and the
prompt row has exactly one writer. **Do not add buffer wiring, stale-buffer detection, a divergence
view or a `409` path.** `021` made the same exclusion for the book-level prompt, for the same reason.
