## Auth seam (decision 3)
`src/auth.ts` ships the minimum `client.ts` needs (Bearer token accessor).
Feature 004 will expand `auth.ts` (current-user, real logout/redirect) and add
the App.tsx token gate. Keep `auth.ts` free of any `src/api/` import so the
one-way dependency direction (`api/` → `auth.ts`) holds.

## No runtime validation
No zod / io-ts. Return values are cast (`res.json() as T`); the backend
(Pydantic) is the single source of truth for shapes. Strict TS is the safety net.

## types/ grep rule
Any type that appears in an `api/` function signature lives in `src/types/`.
`common.d.ts` is the shared seed; the health DTO arrives in step 003
(`health.d.ts`). Keep DTOs pure wire shapes — no methods/classes/getters.

See `context.md` for the feature-wide API-layer rules and the full decision list.
