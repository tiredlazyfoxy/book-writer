## Backend contract (from 001)
`GET /api/health` returns `{ status: "ok", db: "ready" }` — both fields `str`.
`src/types/health.d.ts` must be `{ status: string; db: string }`, matching 1:1.
See `context.md` "Backend contract this feature consumes".

## MobX page-state pattern (the pattern this page bootstraps)
Mirror the reference page-state shape from
`D:/GitRoot/_TextGens/LLMRPTextOnlyProject/frontend/src/user/pages/` (a page +
adjacent `*PageState.ts`), applying `frontend.md`'s MobX hard rules:

- `HealthPageState` uses `makeAutoObservable(this)`; holds the trio
  `health` / `healthStatus` / `healthError`; **no methods**.
- `loadHealth(state, signal)` is a top-level function in the same file:
  set `healthStatus = 'loading'`; `await healthApi.getHealth(signal)`;
  `runInAction` on success (`health` + `healthStatus = 'ready'`);
  on error, early-return if `signal.aborted`, else `runInAction`
  (`healthStatus = 'error'` + `healthError`).
- `HealthPage` is `observer(function ...)`; `const [state] = useState(() => new
  HealthPageState())`; mount `useEffect(() => { const c = new AbortController();
  void loadHealth(state, c.signal); return () => c.abort(); }, [])`; reads
  `state.*` directly in JSX.

## api/ resource module shape
`src/api/health.ts`: `const BASE = "/api/health"`; `getHealth(signal?)` calls
`request<HealthResponse>` (from `./client`) and returns the result; `signal?`
last. Namespace-imported as `import * as healthApi from '../api/health'`.
