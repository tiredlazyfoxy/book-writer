# Step 001 — MPA skeleton: tooling, config, three entries, theming

## Goal
Create the buildable Vite multi-page skeleton — package/tsconfig/vite config,
theming, and the three entry React trees (User, Admin, Login) each rendering a
placeholder — so `npm install`, `npm run build`, and `npm run dev` all succeed
and every entry serves. (Config-heavy scaffold: many small files form one
indivisible buildable unit.)

## Interface intent

- **`package.json`** — declares `"type": "module"`, the three npm scripts
  (`dev` runs Vite on port 8194, `build` runs `tsc` then `vite build`,
  `preview` runs `vite preview`), and the exact dependency/devDependency set
  from `context.md`'s reference notes (Mantine core/form/hooks, tabler icons,
  mobx, mobx-react-lite, react/react-dom, react-markdown, react-router-dom;
  dev: types, plugin-react, typescript, vite). Project name is BookWriter-based.
- **`tsconfig.json`** — single file, `"include": ["src"]`, carrying the exact
  strict flag set from `frontend.md` (`strict`, `noUnusedLocals`,
  `noUnusedParameters`, `noFallthroughCasesInSwitch`, `noEmit`, `target ES2022`,
  `module ESNext`, `moduleResolution "bundler"`, `jsx "react-jsx"`,
  `lib [ES2023, DOM, DOM.Iterable]`, plus `skipLibCheck`, `isolatedModules`,
  `resolveJsonModule`, `esModuleInterop`, `forceConsistentCasingInFileNames`).
  No `tsconfig.node.json`.
- **`vite.config.ts`** — `defineConfig` with `appType: 'mpa'`,
  `plugins: [react(), spaFallback()]`, three Rollup inputs
  (`user` → `index.html`, `admin` → `admin/index.html`,
  `login` → `login/index.html`), and `server: { port: 8194, proxy: { '/api':
  'http://localhost:8185' } }`. Also defines the **`spaFallback()`** dev plugin:
  a `configureServer` middleware that rewrites `req.url` — requests starting
  with `/api`, `/src`, `/@`, or `/node_modules`, or containing a `.`, pass
  through untouched; `/admin*` rewrites to `/admin/index.html`, `/login*` to
  `/login/index.html`, everything else to `/index.html`.
- **`theme.ts`** — a single `createTheme({...})` with a custom primary palette
  (custom 10-shade scale) and a custom `colors.dark` 10-shade scale, plus
  `defaultRadius`, `fontFamily`, `headings.fontWeight`, and a few component
  default props (e.g. `Button` / `TextInput` → `variant: "filled"`). Exports the
  theme as the default/named export the App files import.
- **`global.css`** — box-sizing reset; `html, body, #root { height: 100%;
  margin: 0 }`; body uses `var(--mantine-color-body)` / text color; plus a
  `.md-body` react-markdown style block.
- **`index.html` / `admin/index.html` / `login/index.html`** — each a minimal
  HTML document with a BookWriter `<title>`, a `<div id="root">`, and one module
  `<script type="module">` pointing at its entry (`/src/user/main.tsx`,
  `/src/admin/main.tsx`, `/src/login/main.tsx` respectively).
- **`src/vite-env.d.ts`** — the single line `/// <reference types="vite/client" />`.
- **`src/user/main.tsx`** — minimal: `createRoot(document.getElementById('root'))`
  renders `<StrictMode><App /></StrictMode>` from `./App`.
- **`src/user/App.tsx`** — an `observer` component that imports
  `@mantine/core/styles.css`, then `../global.css`, then the theme; renders
  `<MantineProvider theme={theme} defaultColorScheme="dark">` wrapping a
  `<BrowserRouter>` with a single placeholder route showing BookWriter User
  placeholder content. (Step 003 will replace the placeholder route with the
  health route — see `context.md`.)
- **`src/admin/main.tsx`** — same shape as the user main, rendering the admin
  `App`.
- **`src/admin/App.tsx`** — same shape as the user App but the `<BrowserRouter>`
  carries `basename="/admin"` and renders an Admin placeholder route.
- **`src/login/main.tsx`** — minimal: renders `<StrictMode><Login /></StrictMode>`
  from `./Login`. No Router, no page state.
- **`src/login/Login.tsx`** — an `observer` component owning its own
  `MantineProvider defaultColorScheme="dark"` + the CSS/theme imports, rendering
  a bare centered placeholder (e.g. "Login (coming soon)"). No form, no fields,
  no auth wiring (decision 1).
- **`src/utils/.gitkeep`, `src/components/.gitkeep`** — empty placeholders that
  establish the shared folder layout without shipping shells (decision 4).

## Definition of done
1. `[manual/live]` `cd frontend && npm install` completes without error and
   produces `node_modules`.
2. `[manual/live]` `cd frontend && npm run build` (i.e. `tsc && vite build`)
   exits clean — no TypeScript errors and a successful Vite bundle emitting all
   three entry chunks (user, admin, login).
3. `[manual/live]` `cd frontend && npx tsc --noEmit` reports no type errors.
4. `[manual/live]` `cd frontend && npm run dev` starts Vite on port 8194 and
   each entry serves its placeholder: `/` (User), `/admin` (Admin), `/login`
   (Login) each render without a blank screen or console error.
5. `[manual/live]` Dark is the active color scheme on all three entries (each
   `MantineProvider` mounts with `defaultColorScheme="dark"`).
6. `[manual/live]` Deep-link resolution works in dev via `spaFallback`: loading
   a non-root path under `/` and under `/admin` (e.g. `/anything`,
   `/admin/anything`) serves the correct entry `index.html` rather than a 404,
   while `/api`, `/src`, and asset requests (paths containing `.`) pass through.
7. `[manual/live]` No `nginx/`, docker-compose, or `frontend/Dockerfile` files
   are created (decision 2); no auth/token or login-form code is present
   (decisions 1, 3); no AppLayout/AppHeader/AppSidebar shell is created
   (decision 4).
