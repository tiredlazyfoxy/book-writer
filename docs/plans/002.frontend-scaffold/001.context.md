## Reference anchors (consult, then rename LLMRP → BookWriter, drop domain code)
Mirror these files from `D:/GitRoot/_TextGens/LLMRPTextOnlyProject/frontend`:

- `package.json` — scripts + the dependency/devDependency version set. Copy the
  version ranges from `context.md`'s reference notes; rename the package to a
  BookWriter name.
- `tsconfig.json` — the single-file strict config. There is intentionally **no**
  `tsconfig.node.json`; the Vite config typechecks fine outside `include:["src"]`
  (decision 6).
- `vite.config.ts` — the `appType:"mpa"` + 3-input + proxy config **and** the
  `spaFallback()` plugin. The plugin is a `configureServer` middleware; the
  pass-through predicate is: `req.url` starts with `/api` | `/src` | `/@` |
  `/node_modules`, OR `req.url.includes(".")` → `next()`; else `/admin*` →
  `/admin/index.html`, `/login*` → `/login/index.html`, else → `/index.html`.
- `theme.ts` + `global.css` — the `createTheme()` custom primary + `colors.dark`
  scale, and the CSS reset + `.md-body` block.
- `index.html`, `admin/index.html`, `login/index.html` — the `<div id="root">`
  + single module-script pattern.
- `src/user/main.tsx` + `src/user/App.tsx` and `src/admin/*` — the minimal
  `createRoot` main and the `MantineProvider` + `BrowserRouter` App. Admin's
  `BrowserRouter` takes `basename="/admin"`.
- `src/login/main.tsx` + `src/login/Login.tsx` — note the reference Login is the
  full auth form; **ship a bare placeholder instead** (decision 1). Keep only
  the "Login owns its own MantineProvider + CSS imports" structure.
- `src/vite-env.d.ts` — the one-line vite/client reference.
