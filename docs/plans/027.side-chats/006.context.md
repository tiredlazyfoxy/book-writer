## Gotchas local to this step

- **Book id.** `ChatPaneState` holds no book id by design (`frontend-workspace.md` → the no-book-id
  rule). `ChatPane` receives it as a prop and passes it to `Composer` / its effects. `MessageList`
  must take it as a **prop** too. Because `ChatPane.tsx` is step 007's source file, this step
  declares the prop as **optional** on `MessageList` (actions are rendered disabled when it is
  absent) and step 007 wires it — the same forward-only split `026` used for the memos placeholder.
  State this in the component docstring so the optional prop is not read as a design.
- The group container is `role="group"` + `aria-label="Side chat"` for **both** active and finished
  groups; the visible header `Text` carries the differing label. Tests find the container by role
  and name, the label by text.
- The expand / collapse control is icon-only → its `aria-label` **swaps** with state, like Send /
  Stop; do not render two controls and hide one.
- `MessageRow` keeps `data-role` attributes — DoD-8 asserts on them as the existing regression
  handle.
