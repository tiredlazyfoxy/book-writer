## Gotchas local to this step

- `renderedTranscript` must be a `get` computed **over `renderedMessages`**, not over `messages`,
  so the streaming placeholder and every existing per-message derivation (keys, reasoning, trace)
  come for free and the group holds the same `RenderedMessage` objects `MessageRow` (step 006) will
  render.
- A run breaks on **any** change of `sideChatId` — `A → B` starts a new group with no main-line row
  between them (DoD-4). `null → A` opens a group, `A → null` closes it.
- `expandedSideChats` is written as a **whole new object** (`{ ...state.expandedSideChats, [id]:
  !current }`) per the per-key-status rule; never mutate a key in place.
- The union's type name is the skeleton's to freeze; the step file names the two `kind` literals
  and the field names, which the specs and step 006 bind to.
