## Gotchas local to this step

- The action trio has **no `data` member** by design — an action's result is a chat and/or a message
  array that already live in `chats` / `messages`; a parallel copy would be a second source of truth.
- Guard each effect on its computed **inside** the function, not only in the component — the
  component's `disabled` is presentation; the guard is what makes DoD-11 hold.
- `deleteSideChat` clears `sideChatDeleteConfirm` on both outcomes; leaving the modal open over an
  error banner would show two conflicting states.
- Whole-array swap for `messages`, whole-object replace for the `chats` entry — never `push` /
  `splice` into the observable in place.
