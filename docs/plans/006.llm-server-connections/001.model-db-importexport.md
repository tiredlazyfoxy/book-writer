# Step 001 — `LlmServer` model + db module + import/export codec

## Goal

Add the `LlmServer` table, register it for `create_all`, provide its session-free
db data-access module (including the codebase's first DELETE and the
clear-all-then-set embedding primitives), and add its JSONL import/export codec in
the same change (the "model added = import/export in same change" unit).

## Source files

backend/app/models/llm_server.py
backend/app/db/engine.py
backend/app/db/llm_servers.py
backend/app/services/db_import_export.py

## Test files

backend/tests/db/test_llm_servers.py
backend/tests/services/test_db_import_export_llm_servers.py

## Interface intent

- **`LlmServer`** (in `app/models/llm_server.py`) — the single SQLModel table
  (`table=True`) per **D1**: `id` (autoincrement int PK), `name`, `backend_type`,
  `base_url`, `api_key` (nullable, stored raw or as a `"$ENV_VAR"` token),
  `enabled_models` (TEXT, JSON-encoded `list[str]`, defaults to the empty-list
  string), `is_active` (default true), `is_embedding` (default false),
  `embedding_model` (nullable), `created_at`, `modified_at` (nullable datetimes).
  No logic on the model.
- **`app/db/engine.py`** — amend **only** the model-registration hook to
  `import app.models.llm_server  # noqa: F401` so `create_all` sees the table
  (D1). No other change to this file.
- **`app/db/llm_servers.py`** — the session-free data-access module (one session per
  call via `get_standalone_session()`; `AsyncSession`/`select()`/ORM types never
  leak). Functions: **`get_by_id`** (returns the row or `None`); **`get_all`**
  (all rows ordered by name); **`get_active`** (only `is_active` rows, ordered by
  name); **`create`** (persists a new `LlmServer`, returns the persisted row with its
  assigned id); **`update`** (persists changes to a given row, returns nothing);
  **`delete`** (removes the row for an id, returning `True` when a row was removed and
  `False` when none matched — the first delete pattern in the codebase);
  **`clear_all_embedding`** (a bulk `sqlalchemy.update()` clearing `is_embedding`
  across all rows — the one sanctioned raw-SQLAlchemy spot inside `db/`, per D5);
  **`get_embedding_server`** (the single row currently flagged `is_embedding`, or
  `None`).
- **`app/services/db_import_export.py`** — add the codec pair
  **`_llm_server_to_dict`** (serializes a `LlmServer` to a JSON-safe dict:
  `enabled_models` kept as its JSON string, `api_key` written verbatim per D6,
  datetimes via the existing isoformat helper) and **`_dict_to_llm_server`**
  (reconstructs a `LlmServer`, with `.get(...)` defaults for
  `is_active`/`is_embedding`/`enabled_models`), and append the tuple
  `("llm_servers", LlmServer, _llm_server_to_dict, _dict_to_llm_server)` to
  `TABLE_REGISTRY` **after** the existing `users` entry (D6). No other registry
  reordering.

## Definition of done

1. `[test]` **US-010.AC-1** — a `LlmServer` created via `db.llm_servers.create`
   (name, backend_type, base_url, api_key token, enabled_models, flags all set) is
   retrievable by `get_by_id` with every field round-tripped, and appears in
   `get_all`.
2. `[test]` **US-013.AC-2** — `db.llm_servers.delete(id)` removes the row (a
   subsequent `get_by_id` returns `None`) and returns `True`; `delete` on an id with
   no matching row returns `False` (the first delete pattern).
3. `[test]` decision **D5** — `clear_all_embedding()` clears `is_embedding` on every
   row; `get_embedding_server()` returns the single row currently flagged (and
   `None` when none is flagged).
4. `[test]` decision **D1/D5** — `get_all` returns rows ordered by name and
   `get_active` returns only `is_active` rows (ordered by name), excluding inactive
   ones.
5. `[test]` decision **D6** — a `LlmServer` round-trips through
   `_llm_server_to_dict` → `_dict_to_llm_server` preserving all fields, with
   `enabled_models` preserved as its JSON string and `api_key` preserved verbatim
   (the `$ENV` token / literal is not masked on export); and `TABLE_REGISTRY`
   contains a tuple whose zip filename is `"llm_servers"` and whose model class is
   `LlmServer`, positioned after the `users` entry.
