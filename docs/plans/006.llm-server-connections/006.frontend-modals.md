# Step 006 — Admin SPA LLM-servers modals (form / models / embedding)

## Goal

Complete the LLM-servers UI with the three cohesive modals — register/edit form,
model probe+enable, embedding designation — each a drafts-in-state form with
`get`-computed validation and separate server errors, wired into the list page for the
probe → enable → designate flow. (Kept as one step: three cohesive modals, matching
005's precedent of one step for its three user-mutation modals.)

## Interface intent

- **`serverFormDraft.ts` / `ServerFormModal.tsx`** — a draft class (observable fields
  for name / backend_type / base_url / api_key / is_active, `get`-computed validation +
  `canSubmit`, a separate `serverErrors` merged into the errors getter) and an
  `observer` modal used for both **create** and **edit**. `backend_type` is a select
  limited to the `"llama-swap" | "openai"` option list (D2). Submit calls
  `createServer` or `updateServer` and refreshes the page list; the modal exposes a
  **"Select Models"** action opening the models modal.
- **`modelsModalDraft.ts` / `ModelsModal.tsx`** — a draft holding the enabled-set
  selection + the probe async trio; an `observer` modal that **probes on open**
  (`probeModels`) and renders `available ∪ already-enabled` as a **checkbox** list
  (so a failed probe does not lose prior selections). A probe error is surfaced
  in-modal without clearing the current selection. Save calls `setEnabledModels`
  (US-012).
- **`embeddingModalDraft.ts` / `EmbeddingModal.tsx`** — a draft holding the single
  selected model + the probe async trio; an `observer` modal that **probes on open**
  and renders a single-select **radio** list. Submit calls `setEmbedding` designating
  the server + model (replaces any prior, US-014).
- **`LlmServersPage.tsx`** (amend) — hold each modal's open/target via
  **component-local `useState`** (not page state), wire the "New server" / per-row
  "Edit" / "Select Models" / "Set Embedding" actions to open the modals, and reload the
  list after each modal's mutation succeeds.

## Definition of done

1. `[manual/live]` **US-010.AC-1 / US-013.AC-1 (UI)** — `ServerFormModal` creates a new
   server and edits an existing one; drafts live in component-local state with
   `get`-computed validation + `canSubmit` + separate `serverErrors` (no Mantine
   `useForm`); submit calls `createServer`/`updateServer` and the list refreshes.
2. `[manual/live]` **US-010.AC-2 (UI)** — the form's `backend_type` control is a select
   limited to the `"llama-swap" | "openai"` options, so an out-of-set type can't be
   submitted.
3. `[manual/live]` **US-011.AC-1 / US-011.AC-2 / US-012.AC-1 (UI)** — `ModelsModal`
   probes on open (`probeModels`), shows `available ∪ already-enabled` as a checkbox
   list, surfaces a probe error without losing the current selection, and saves the
   chosen subset via `setEnabledModels`.
4. `[manual/live]` **US-014.AC-1 / US-014.AC-2 (UI)** — `EmbeddingModal` probes on open,
   offers a single-select radio, and on submit calls `setEmbedding` designating the
   server + model (replacing any prior designation).
5. `[manual/live]` decision **D9 (conventions)** — modal open/target flags are
   component-local `useState` (not page state); every modal + draft follows the
   `observer` + drafts-in-state + external effect pattern; `npm run build` passes with
   no `any`.
