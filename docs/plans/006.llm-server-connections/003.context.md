Step-local notes:

- **This step amends `services/llm_servers.py`** (created in step 002) — it adds
  `_create_client` + `probe_models` only; the step-002 CRUD/enable/embedding functions
  and `LlmServerError` are given. The `probe-failed` discriminator case was reserved in
  step 002's context; use it here.
- **Air-gap for tests:** `_create_client` is the monkeypatch seam. Because
  `probe_models` resolves the key via `secrets.resolve_env_ref` *before* calling
  `_create_client`, the env-not-set path (DoD-4) is reachable in tests even when
  `_create_client` is faked. Expected model lists come from the test's own fake, never
  from the real `llm` library — no network, no live server (matches the in-process
  harness).
- **`llm` client wiring (D8, confirmed against the installed package):** import the
  library as the module `llm`; route all outbound LLM calls through it (never direct
  HTTP). `base_url` must already contain `/v1` — the client appends `/models` raw; do
  **not** auto-append. Unreachable → raw `aiohttp.ClientError` (not wrapped);
  HTTP/auth failure → `llm.LLMError`; keyless `openai` client → `ValueError` at
  construction. Catch all three.
- **The route (step 004) maps probe-failed → 502**; not-found → 404; env-not-set →
  400. This step only raises the typed cases; it does not know about HTTP status.
