# Step 002 — schemas + `$ENV` resolver + service (CRUD / enable / embedding / masking)

## Goal

Build the request/response DTOs, the shared `$ENV` secret resolver, and the LLM-server
service's non-probe business logic: CRUD, enable-models, embedding designation
(clear-all-then-set), the secret-masking response mapper, and backend-type validation
with a typed error carrying a case discriminator.

## Source files

backend/app/models/schemas/llm_servers.py
backend/app/services/secrets.py
backend/app/services/llm_servers.py

## Test files

backend/tests/services/test_secrets.py
backend/tests/services/test_llm_servers.py

## Interface intent

- **`app/models/schemas/llm_servers.py`** — Pydantic `BaseModel`s (D1/D3):
  `CreateLlmServerRequest` (`name`, `backend_type`, `base_url`, optional `api_key`,
  `is_active` default true); `UpdateLlmServerRequest` (all fields optional);
  `LlmServerResponse` (`id:int`, `name`, `backend_type`, `base_url`,
  **`has_api_key:bool`**, `enabled_models:list[str]`, `is_active`, `is_embedding`,
  `embedding_model`, `created_at`, `modified_at` — **no `api_key` field**);
  `LlmServersListResponse` (`items`); `AvailableModelsResponse` (`models:list[str]`);
  `EnabledModelsRequest` (`enabled_models:list[str]`); `SetEmbeddingRequest`
  (`model:str`); `EmbeddingConfigResponse` (`server_id`, `server_name`, `base_url`,
  `backend_type`, `model`, `has_api_key`).
- **`app/services/secrets.py`** → **`resolve_env_ref`** (D3) — the ONE shared
  resolver: `None`→`None`; a value starting with `$` → return `os.environ[name]`,
  raising a typed **env-not-set** error when that variable is unset; any other value
  → return it verbatim. Called only at use time (step 003 uses it during probe).
- **`app/services/llm_servers.py`** — the service (no `session`/`select()` here;
  all persistence via `db.llm_servers`). Functions:
  - a **private response mapper** (`_to_response`) building a `LlmServerResponse` from
    an `LlmServer` by hand: computes `has_api_key = api_key is not None and
    api_key != ""` (D3), decodes `enabled_models` JSON to `list[str]`, copies only
    non-secret fields (never dumps the ORM, never exposes `api_key`).
  - **`get_all_servers`** — every server (via `db.llm_servers.get_all`) mapped to
    `LlmServerResponse`, ordered by name.
  - a single-get helper returning one server's `LlmServerResponse` (not-found →
    typed error).
  - **`create_server`** — validates required fields present/non-empty (missing-field
    case) and `backend_type ∈ {"llama-swap","openai"}` (invalid-backend-type case,
    the module constant per D2), persists a new `LlmServer` via `db.llm_servers.create`
    (setting `created_at`/`modified_at`), returns its `LlmServerResponse`.
  - **`update_server`** — partial update: fetch the target (not-found case), apply only
    provided fields; **`api_key == ""` coerces to `None`** (clear-key), an omitted/None
    `api_key` leaves the stored key unchanged; re-validate `backend_type` if provided;
    bump `modified_at`; persist via `db.llm_servers.update`; return the response.
  - **`delete_server`** — deletes via `db.llm_servers.delete`; not-found (delete
    returned `False`) → typed error.
  - **`set_enabled_models`** — fetch (not-found case), `json.dumps` the given subset
    into `enabled_models`, persist, return the response with the decoded list.
  - **`set_embedding_server`** — fetch (not-found case), call
    `db.llm_servers.clear_all_embedding()` then set `is_embedding=True` +
    `embedding_model=model` on the target and persist (D5 clear-all-then-set,
    US-014.AC-2 "replaces prior").
  - **`clear_embedding_server`** — clear all embedding flags (US-014 clear path).
  - **`get_embedding_config`** — return the current `EmbeddingConfigResponse` from
    `db.llm_servers.get_embedding_server` (or a null/empty indicator when none).
  - a **typed `LlmServerError`** carrying a **case discriminator**
    (invalid-backend-type / missing-field / not-found / env-not-set / probe-failed —
    same pattern as 005's admin error) that step 004's route maps to status. The
    env-not-set case is raised from `resolve_env_ref`; probe-failed is added in step
    003; this step raises invalid-backend-type / missing-field / not-found.

## Definition of done

1. `[test]` **US-010.AC-1** — `create_server` with name + backend_type + base_url
   (+ api_key) persists the server and returns a `LlmServerResponse` reflecting the
   supplied fields.
2. `[test]` **US-010.AC-2** — `create_server` with a `backend_type` outside
   `{"llama-swap","openai"}` raises `LlmServerError` with the invalid-backend-type
   case (no server created).
3. `[test]` **US-010.AC-3** — `create_server` with a required field
   (name / backend_type / base_url) empty raises `LlmServerError` with the
   missing-field case.
4. `[test]` **US-013.AC-1** — `update_server` applies provided fields so the stored
   record reflects the new values; an omitted `api_key` leaves the stored key
   unchanged, while `api_key == ""` clears it (subsequent response shows
   `has_api_key` false).
5. `[test]` **US-012.AC-1** — `set_enabled_models` persists the given subset; the
   returned response's `enabled_models` is the decoded `list[str]`.
6. `[test]` **US-014.AC-1** — `set_embedding_server(id, model)` records the target as
   the embedding provider (`is_embedding` true + `embedding_model` set);
   `get_embedding_config` returns that server + model.
7. `[test]` **US-014.AC-2** — after designating server A, designating server B leaves
   exactly one server flagged (`is_embedding` true only on B, cleared on A).
8. `[test]` **US-021.AC-1** — `resolve_env_ref`: `None`→`None`; `"$FOO"` returns the
   value of `os.environ["FOO"]`; a literal string returns verbatim; a `"$FOO"` whose
   variable is unset raises the env-not-set typed error.
9. `[test]` **US-021.AC-2** — a `LlmServerResponse` from `_to_response` exposes no
   `api_key` field and does expose `has_api_key`, computed as `api_key is not None
   and api_key != ""` (true for a stored token/literal, false for `None`/empty).
10. `[test]` decision **D7 (not-found)** — `update_server`, `delete_server`,
    `set_enabled_models`, and `set_embedding_server` on a non-existent id each raise
    `LlmServerError` with the not-found case.
