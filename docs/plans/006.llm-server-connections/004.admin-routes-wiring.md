# Step 004 — admin routes + router wiring (HTTP surface)

## Goal

Expose the LLM-server service over HTTP: nine admin-gated endpoints under
`/api/admin/llm-servers`, with the static `/embedding` routes declared before the
`/{server_id}` param routes, each mapping the service's typed error to the status
taxonomy, and wire the router into the app.

## Source files

backend/app/routes/admin/llm_servers.py
backend/app/routes/admin/__init__.py
backend/app/main.py

## Test files

backend/tests/routes/admin/test_llm_servers.py

## Interface intent

- **`app/routes/admin/llm_servers.py`** — an `APIRouter` with prefix
  `/api/admin/llm-servers`, every endpoint declaring `Depends(require_role(admin))`
  (D7). Each handler stays HTTP-only: parse → call one `services.llm_servers`
  function → map `LlmServerError` by its case to a status → return the schema. The
  nine endpoints (D5 ordering — declare the two static `/embedding` routes **before**
  the `/{server_id}` param routes so `/embedding` is not captured as a server id):
  - **`GET ""`** — list servers → `LlmServersListResponse`, 200.
  - **`POST ""`** — create from `CreateLlmServerRequest` → `LlmServerResponse`, 201.
  - **`GET "/embedding"`** — current embedding config → `EmbeddingConfigResponse`, 200.
  - **`DELETE "/embedding"`** — clear the embedding designation, 204.
  - **`PUT "/{server_id}"`** — update from `UpdateLlmServerRequest` →
    `LlmServerResponse`, 200 (404 if missing).
  - **`DELETE "/{server_id}"`** — delete the server, 204 (404 if missing).
  - **`GET "/{server_id}/available-models"`** — probe/test-connection →
    `AvailableModelsResponse`, 200 (502 on probe failure).
  - **`PUT "/{server_id}/enabled-models"`** — set the enabled subset from
    `EnabledModelsRequest` → `LlmServerResponse`, 200.
  - **`PUT "/{server_id}/embedding"`** — designate this server + model as the
    embedding provider from `SetEmbeddingRequest`, 204.
  - The **typed-error → status map** (D7): missing-field / invalid-backend-type /
    env-not-set → 400; not-found → 404; probe-failed → **502**. (Non-admin → 403 is
    produced by `require_role`.)
- **`app/routes/admin/__init__.py`** — amend only if the admin package aggregates
  routers for mounting; otherwise leave the 005 marker as-is.
- **`app/main.py`** — include the llm-servers router on the app (composition root),
  alongside the existing auth + admin-users routers.

## Definition of done

1. `[test]` decision **D7 (gating)** — `GET /api/admin/llm-servers` with an
   `author`-role token returns 403; with an `admin`-role token returns 200.
2. `[test]` **US-010.AC-1** — `POST /api/admin/llm-servers` with name + backend_type +
   base_url returns 201, and a subsequent `GET ""` lists the created server.
3. `[test]` **US-010.AC-2** — `POST` with a `backend_type` outside
   `{llama-swap, openai}` returns 400.
4. `[test]` **US-010.AC-3** — `POST` with an empty required field returns 400.
5. `[test]` **US-013.AC-1** — `PUT /api/admin/llm-servers/{id}` updates fields; the
   updated server in a subsequent `GET ""` list reflects the new values.
6. `[test]` **US-013.AC-2** — `DELETE /api/admin/llm-servers/{id}` returns 204 and the
   server no longer appears in `GET ""`; `DELETE` on a non-existent id returns 404.
7. `[test]` **US-012.AC-1** — `PUT /api/admin/llm-servers/{id}/enabled-models`
   persists the subset; the server in a subsequent `GET ""` shows that
   `enabled_models` list.
8. `[test]` **US-011.AC-1** — `GET /api/admin/llm-servers/{id}/available-models` with
   `_create_client` monkeypatched to a fake returns 200 and the reported model list.
9. `[test]` **US-011.AC-2** — the same endpoint, with the fake client raising
   `aiohttp.ClientError`, returns **502** and no model list.
10. `[test]` **US-014.AC-1 / US-014.AC-2** — `PUT /{id}/embedding` designates the
    server+model (`GET /api/admin/llm-servers/embedding` reflects it); designating a
    different server replaces the prior; `DELETE /api/admin/llm-servers/embedding`
    clears it (204). (These passing also confirm the static `/embedding` routes
    resolve ahead of `/{server_id}`, D5.)
11. `[test]` **US-021.AC-2** — no `POST`/`GET ""` response body contains an `api_key`
    (or any raw-key) field; each server object carries `has_api_key`.
12. `[test]` decision **D7 (not-found)** — `PUT`/`DELETE`/`enabled-models`/`embedding`
    on a non-existent `server_id` returns 404.
