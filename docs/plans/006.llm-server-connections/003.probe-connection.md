# Step 003 — probe / test-connection (first `llm`-client wiring)

## Goal

Add the fused test-connection + model-probe to the LLM-server service: resolve the
API key at use time, construct the right `llm` client by backend type, list the
models the server reports, and surface the three failure modes as the typed
probe-failed error — the codebase's first `llm`-client wiring.

## Source files

backend/app/services/llm_servers.py

## Test files

backend/tests/services/test_llm_servers_probe.py

## Interface intent

- **`_create_client`** (private, in `app/services/llm_servers.py`) — given a server
  (and the resolved key), construct the appropriate `llm` client for its
  `backend_type` (OpenAI-compatible vs llama-swap), per D4/D8. This is the seam tests
  monkeypatch (its frozen signature is the boundary; tests never touch the real `llm`
  library).
- **`probe_models`** (in `app/services/llm_servers.py`) — given a server id (D4):
  fetch the server (not-found case), **resolve its `api_key` via
  `secrets.resolve_env_ref` at use time** (an unset `$ENV` surfaces the env-not-set
  case *before* any client construction), construct the client via `_create_client`,
  call `await client.list_models()`, and return the model names **sorted** as a
  `list[str]`. The probe changes no server record. It catches the three failure
  types around construction + `list_models()` — `aiohttp.ClientError` (unreachable),
  `llm.LLMError` (HTTP/auth), and `ValueError` (keyless OpenAI client) — and
  re-raises them as `LlmServerError` with the **probe-failed** case (D8), returning no
  model list on failure.

## Definition of done

1. `[test]` **US-011.AC-1** — with `_create_client` monkeypatched to return a fake
   client whose `list_models()` yields a known list, `probe_models` returns exactly
   that list, sorted, and leaves the server record unchanged.
2. `[test]` **US-011.AC-2** — when the monkeypatched client's construction or
   `list_models()` raises `aiohttp.ClientError`, `probe_models` raises `LlmServerError`
   with the probe-failed case and returns no model list.
3. `[test]` decision **D8** — a monkeypatched client raising `llm.LLMError`, and one
   raising `ValueError` (keyless OpenAI), each also surface as the probe-failed case.
4. `[test]` **US-021.AC-1** — `probe_models` resolves a stored `"$ENV"` `api_key` at
   use time: with the env var set, the value passed toward the client is the resolved
   secret (observable via the fake client capturing its key); with the env var unset,
   `probe_models` raises the env-not-set case before constructing any client.

## Dependencies

Step 002 (the service, `LlmServerError` with its case discriminator, and
`secrets.resolve_env_ref`).
