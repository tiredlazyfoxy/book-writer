# Step 005 — Admin SPA LLM-servers base (types + api + list page + nav)

## Goal

module, the LLM-servers list page (list + delete + row badges + clear-embedding) with
its page state and external effect functions, a route, and a minimal

## Interface intent

- **`src/types/llmServers.d.ts`** — hand-written DTO `.d.ts` matching the backend
  schemas 1:1: `LlmServer` (response shape incl. `id:number`, `has_api_key:boolean`,
  `enabled_models:string[]`, `is_embedding`, `embedding_model`, timestamps — **no
  `api_key`**), the create/update request shapes, `AvailableModels`,
  `EnabledModelsRequest`, `SetEmbeddingRequest`, `EmbeddingConfig`, the
  **`"llama-swap" | "openai"`** backend-type union, and a backend-type option list for
  the form select (D2/D9). No `any`, no zod.
- **`src/api/llmServers.ts`** — one resource module over the shared `request<T>` from
  `api/client.ts`, `signal?` last on every fn: `listServers`, `createServer`,
  `updateServer`, `deleteServer`, `probeModels`, `setEnabledModels`, `setEmbedding`,
  `clearEmbedding` (D9). Import in state files via `import * as llmServersApi from
  '../../api/llmServers'`.
- **`src/admin/pages/llmServersPageState.ts`** — `LlmServersPageState`
  (`makeAutoObservable`) holding **only** the async trio
  `servers`/`serversStatus`/`serversError` (no effectful methods, per the MobX rules);
  plus external effect functions `(state, …, signal)` with `runInAction`:
  **`loadServers`** (fetch + set trio), **`deleteServerAction`** (delete then reload),
  **`clearEmbeddingAction`** (clear then reload).
- **`src/admin/pages/LlmServersPage.tsx`** — `observer` page component: owns the state
  via `useState(() => new LlmServersPageState())`, a page-level `useEffect` that loads
  on mount and aborts on unmount, and a table of servers with per-row badges
  (backend type, `has_api_key` presence, enabled-model count, embedding indicator) and
  a per-row delete action + a clear-embedding action. Modal wiring is step 006 (leave a
  seam). No `useCallback`/`useMemo`; handlers are inner functions.
- **`src/admin/routes.tsx`** — add the `/admin/llm-servers` route pointing at
  `LlmServersPage` (keep the existing users route).
- **`src/admin/App.tsx`** — add a minimal `Users | LLM Servers` nav (the growth 005
  deferred to "when 006 adds pages"); **keep** the 004 mount-time token-gate and the
  minimal local layout. Do **not** build a heavyweight shared sidebar framework.

## Definition of done

1. `[manual/live]` **US-013.AC-2 (UI)** — the Admin SPA nav's "LLM Servers" link
   reaches a page listing registered servers (via `listServers`); a per-row delete
   action calls `deleteServer` and the row disappears after the list reloads.
2. `[manual/live]` **US-021.AC-2 (UI)** — each row shows an API-key **presence** badge
   driven by `has_api_key`, and no key value is ever displayed (the DTO carries none).
3. `[manual/live]` **US-014 (UI)** — a row/indicator shows which server+model is the
   current embedding provider (from `is_embedding`/`embedding_model`), and a
   clear-embedding action calls `clearEmbedding` and reloads.
4. `[manual/live]` decision **D9 (MobX conventions)** — the page owns
   `LlmServersPageState` (async trio only, `makeAutoObservable`, no effectful methods);
   loads/deletes/clears run through external `(state, …, signal)` functions with
   `runInAction`; the page-level `useEffect` loads on mount and aborts on unmount;
   every component is `observer`-wrapped; all HTTP goes through `api/llmServers.ts`
   over the shared `request<T>`.
5. `[manual/live]` decision **D2/D9 (types)** — `types/llmServers.d.ts` defines the
   `"llama-swap" | "openai"` union and a backend-type option list, and the response
   type carries no `api_key` field; `npm run build` (tsc + vite) passes with no `any`.
