## Password-policy placement (decision 4)

003's `create_database` already enforces min-length-8 + confirm-match in the
service layer. Reuse that policy — do **not** write a third copy. If 003 exposed
the check as a standalone callable, import and call it. If it is inlined inside
`create_database`, add the shared validator here (co-located with the password
primitives in `app/services/auth.py`, next to `hash_password`) and have
`create_user` / `set_user_password` call it. **Do not refactor 003's
`services/setup.py` in this step** — `setup.py` is outside this step's Source
scope; converging setup onto the shared validator is recorded as a deferred
observation in `outcome.md`, not required work here. The validator raises the
typed error the service surfaces as the password-invalid taxonomy case (→ 400).

## Credential minting (decisions 5–7)

- `hash_password(password)` takes **no salt arg**; there is no `salt` column.
- Create and reset both mint `(pwdhash, signing_key)` and set `last_key_update`;
  `generate_signing_key` is `secrets.token_hex(32)` (from 003). New users start
  with `last_login` null.
- Disable nulls `pwdhash` **and** `jwt_signing_key` only (no `salt`) — this alone
  makes 004's `get_current_user` reject the target on its next request.
- Re-enable is implicit: writing a non-null `pwdhash` + fresh signing key clears
  the disabled state (there is no separate `disabled` flag).

## The derived `active` field (decision 3)

`active = user.pwdhash is not None`, computed **only** in the response mapper. It
is not a `User` column and **must not** become one — no model change, no
import/export codec change. `AdminUserResponse.id` is an **int**.

## `require_role` shape

A dependency factory over `get_current_user`, ladder `{author: 0, admin: 1}`,
insufficient → HTTP 403. Because its inner dependency function receives the caller
via `Depends(get_current_user)`, the test-coder can construct `require_role(admin)`
and invoke the returned function directly with a `User` to assert the ladder
(admin admitted, author refused) without a live request — see DoD-13.
