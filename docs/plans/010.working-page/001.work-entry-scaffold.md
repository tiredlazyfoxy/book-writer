# 001 — work entry scaffold

## Goal

Add the `work` Vite entry (and a minimal stub `read` entry) with the admin-pattern bootstrap, an
auth-only work gate, an `observer` route table with a terminal catch-all, and the bookshelf's first
link into `/work/:bookId`.

## Interface intent

- **`workGate.ts`** — mirrors `src/admin/adminGate.ts` in shape and in documented rationale.
  - A *work access decision* union: allowed, or denied together with the href to redirect to.
  - A **pure resolver** that reads the stored token via `src/auth.ts` and returns that decision with
    no side effects. It is **auth-only**: book membership is not decidable from the JWT, so a
    non-member is surfaced later by the API's 403/404 on the workspace's own load, never here.
    A missing token denies with the login href.
  - An **enforcer** that runs the resolver and, only when denied, calls `navigateTo` exactly once,
    reporting whether access was allowed so the caller can skip rendering.
  - Carry a comment recording, as `adminGate.ts` does, why this is not a `useEffect` gate and not a
    `<WorkGate>` component.
- **`src/work/main.tsx`** — enforces access *outside* React; only on allow does it create the root
  and render the app in `StrictMode`.
- **`src/work/App.tsx`** — `MantineProvider` (shared `theme`, dark default) wrapping a
  `BrowserRouter` with `basename="/work"` wrapping the route element. No shell yet — step 002 adds it.
- **`src/work/routes.tsx`** — an `observer`-wrapped route table exporting the routes element. At this
  step it declares only the terminal catch-all rendering the work not-found page; steps 002–004 nest
  the real routes into it.
- **`src/work/pages/NotFoundPage.tsx`** — a minimal `observer` page: a not-found message and a plain
  anchor back to the bookshelf at `/`.
- **`src/read/main.tsx` / `src/read/App.tsx`** — the reader stub: a Mantine-themed placeholder naming
  the table of contents as the reader's only Stage-2 surface. **No router, no gate, no data** — the
  reader's real build is out of scope per `brief.md`.
- **`frontend/work/index.html` / `frontend/read/index.html`** — copies of the existing entry HTML
  shape, differing only in `<title>` and the module script src.
- **`frontend/vite.config.ts`** — two additional Rollup inputs (`work`, `read`) alongside
  `user` / `admin` / `login`, and two new `spaFallback` branches rewriting `/work…` and `/read…` deep
  links to their own entry HTML, **inserted before the existing catch-all `else`**.
- **`frontend/src/user/pages/BookshelfPage.tsx`** — each owned and shared book row's title cell
  becomes a **plain anchor** to `/work/<book.id>` (a full page load across entries). Nothing else on
  that page changes.

## Definition of done

1. `[test]` The gate's pure resolver allows when a token is present and denies with the login href
   when it is absent, and performs no navigation in either case. (No product AC — mirrors
   `src/admin/adminGate.ts`; `frontend-workspace.md` → "Five Vite entries".)
2. `[test]` The enforcer calls `navigateTo` exactly once on deny and not at all on allow, and reports
   the allow/deny outcome to its caller.
3. `[test]` The work route table renders the not-found page for the entry root (no book id) and for
   an unmatched deep path, and the catch-all is terminal.
4. `[test]` Every bookshelf row — owned and shared alike — exposes a plain anchor whose `href` is
   exactly `/work/<id>`, and it is not a react-router link. (UC-090's entry point; no AC of its own.)
5. `[manual/live]` `npm run dev` serves deep links `/work/<id>` and `/read/<id>` without a 404,
   confirming the new `spaFallback` branches precede the catch-all `else`.
6. `[manual/live]` `cd frontend && npm run build` is clean and emits five entry bundles, including
   `work/index.html` and `read/index.html`.
7. `[manual/live]` `cd frontend && npm test` is green and `cd frontend && npm run test:types` is clean.
